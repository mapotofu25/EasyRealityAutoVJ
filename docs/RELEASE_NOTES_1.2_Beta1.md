# EasyReality AutoVJ 1.2 Beta1

## 音源输入增益

- 「音源设置」新增 **输入增益** 开关和 `-12 ~ +12 dB` 手动滑块，位置在「单声道分析」下方。
- 只有打开开关时滑块才可拖动；关闭时整组增益控件（标签、滑轨、数值）灰显。
- 拖动/切换是**实时生效**的；不点「应用」直接取消/关窗，会还原到打开对话框前的增益。
- 增益加在**声卡采集之后**，只影响软件内部的电平表、能量/BPM 分析、指纹缓冲和离线锚点。
- 不改变 NDI 音频透传，也不改变现场 PA 的声音。
- 声卡原始峰值 ≥0.999 或增益后 ≥0.999 时，电平表上方**常驻的削波红灯**亮起，并显示红字说明（原始削波 / 增益削波）；软件增益不能恢复削波。
- 表头同时显示「原始峰值」和「补偿后峰值」，避免看起来满了其实声卡已经爆。
- **自动选材保持旧规则**：每个自动层在每次段落切换时，从当前角色/动态档下所有符合条件的素材里随机抽 **8 个**进池；段内在这 8 个里切换，下一次段落再重抽 8 个。
- **跨段落避重**：每个图层记住最近进过池的最多 64 个路径，下一次 roll 优先排除它们；只有候选不够时才回填，避免每次都抽回同一批。
- **素材调用日志**：新增 `%LOCALAPPDATA%\AutoVJ\clip_calls.log`，每次真正切到素材都记一行（时间 / 图层 / 池大小 / 文件路径），可统计哪些素材从未被调用。
- **音频解码兜底**：个别 FLAC 会出现 `soundfile` 报 `flac decoder lost sync`、但 PyAV 能读的情况；解码统一改走 `audio_decode`（soundfile 优先，失败自动退回 PyAV），避免整首歌没有网格/波形。坏帧严重的文件仍需重新获取。
- 增益按「音源类型 + 设备名」分别记忆；换设备/换声卡不会沿用上一台的增益。
- 输入连续偏小会提示「输入偏小，可打开输入增益」。
- 默认关闭、0 dB；不会自动追音量，避免破坏能量段落和 drop 判断。
