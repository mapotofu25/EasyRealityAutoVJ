# 2026-10-28 三项改动：NDI 低延迟开关 / 曲目信息与详情合并 / 关于内容

## 1. NDI 双路输出：本地一路 + 局域网一路

**用户的定义**：「NDI 输出」管**本机**（同机 OBS），「NDI 局域网发送」管**局域网里的机器**。
⇒ 改成**两个互相独立的发送端**（两个 NDI 源），不是同一个开关的两种模式。

| 项 | 本机那路 | 局域网那路 |
|---|---|---|
| 源名 | `<NDI 源名称>` | `<NDI 源名称> (LAN)` |
| 时钟节流 | 保持默认（`clock_video=True`） | **关掉**（`clock_video=False`，帧一到就走） |
| 开关 | 「NDI 输出」 | 「NDI 局域网发送」（**灰化**除非「NDI 输出」已开） |
| 失败影响 | 走原有退避重试 | **独立退避**（0.5s×n，封顶 5s），挂了不影响本机那路 |
| 音频 | 按 `ndi_audio` 配置（默认关） | 只发画面 |

**为什么延迟会小**：NDI 默认 `clock_video=True` 会按提交帧率做时钟节流，等于给每帧排一层队；
局域网那路关掉它，帧一到就走。

实现要点：
- `ndi_out.get_ndi(name)` / `get_ndi_lan(name)` / `close_ndi_lan()` 三个入口，`_inst` 与 `_inst_lan` 分开。
- `engine._ndi_send()`：本机那路成功后，若 `output.ndi_lan` 为真再推一路（`_ndi_lan_fails/_ndi_lan_retry_at` 独立）。
- UI：两个勾选框去掉括号说明文字（「NDI 输出」「NDI 局域网发送」）；
  `_ndi_lan_gate()` 保证「NDI 输出」没勾时局域网那项是**灰的**。
- 关掉「NDI 输出」会同时关掉局域网那路并释放它的 encoder 线程。

## 2.「此曲目信息」与「歌曲详情…」合并成一个入口

- 曲库右键（单选本机曲目）现在只有 **「曲目信息与详情…」** 一项，打开详情页时
  在顶部多一块**只读、可选中复制**的曲目信息（文件 / 歌名 / 艺人 / 曲风 / 曲风来源 /
  时长 / 采样率 / 指纹 ID / 完整路径）。
- 文本**只有一份真源**：`music_detail.info_text(cfg, path)`。
  `ui_main.show_music_info()` 也改调它（码表派生行、导入包里的歌仍然只有轻量弹窗，
  因为本机没有文件、打不开波形详情）。
- 不传 `info_text` 时详情页与原来完全一致（兼容 erlib 侧的同源实现与旧调用）。
