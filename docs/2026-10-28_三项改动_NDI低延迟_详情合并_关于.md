# 2026-10-28 三项改动：NDI 低延迟开关 / 曲目信息与详情合并 / 关于内容

## 1. NDI 局域网发送（低延迟）—— 解决「OBS 里画面比本地晚零点几秒」

**原因**：NDI SDK 建发送端时 `clock_video=True` 会**按提交帧率做时钟节流**，等于给每帧排一层队。
局域网直连时这层缓冲就是那零点几秒。

**做法**：
- 新增配置 `output.ndi_lan`（默认 **False**，不改老行为）。
- 打开后建 sender 用 `Sender(name, "", clock_video=False, clock_audio=True)` —— 视频帧一到就走；
  音频仍保留时钟（音频块是按时间推进的，关掉会突发）。
- 因为 `clock_*` 只能在 `open()` 前定，切换时 `set_lan()` 会 **close() 让下一帧按新参数重建**。
- **门控（用户要求）**：`chk_ndi_lan` 只有「NDI 输出」勾上时才可用；`_ndi_lan_gate()` 统一管，
  `set_ndi_enabled()` 两个分支（成功/失败）都会调它。
- 接线：`config.py` 默认值 + `panels` 勾选框 + `ui_main.set_ndi_lan()` 槽 + `engine._ndi_send` 初始化时 `set_lan()`。
- i18n 三条：勾选框文字 / 灰掉时的提示 / 详细提示。

**验证**：`tools/_test_ui_20261028.py` 断言了「默认 False / set_lan 生效且同值不重建 /
`clock_video = not lan` / NDI 关时控件是灰的、开时才可用」。

> OBS 侧仍建议：NDI 源属性里把 **Syncing 设为 Network**、延迟按需再调；两端都在同一交换机下最稳。

## 2.「此曲目信息」与「歌曲详情…」合并成一个入口

- 曲库右键（单选本机曲目）现在只有 **「曲目信息与详情…」** 一项，打开详情页时
  在顶部多一块**只读、可选中复制**的曲目信息（文件 / 歌名 / 艺人 / 曲风 / 曲风来源 /
  时长 / 采样率 / 指纹 ID / 完整路径）。
- 文本**只有一份真源**：`music_detail.info_text(cfg, path)`。
  `ui_main.show_music_info()` 也改调它（码表派生行、导入包里的歌仍然只有轻量弹窗，
  因为本机没有文件、打不开波形详情）。
- 不传 `info_text` 时详情页与原来完全一致（兼容 erlib 侧的同源实现与旧调用）。
