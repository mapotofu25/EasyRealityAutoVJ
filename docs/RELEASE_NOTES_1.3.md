# EasyReality AutoVJ 1.3 正式版

1.3 是 1.1 正式版之后的正式版本，重点包括：音源输入增益、Build Up（起歌段）、GPU 多屏输出、ERLIB 曲库包 Build Up 同步、主屏设置统一，以及 30fps 显示链路的持续优化。下面按功能域列出完整更新。

## 一、音源与输入增益

- 「音源设置」新增 **输入增益** 开关和 `-12 ~ +12 dB` 手动滑块，位置在「单声道分析」下方。
- 只有打开开关时滑块才能拖动；关闭时标签、滑轨和数值一起灰显。
- 拖动/切换实时生效；不点「应用」直接取消/关窗，会还原到打开对话框前的增益。
- 增益加在**声卡采集之后**，只影响软件内部的电平表、能量/BPM 分析、指纹缓冲和离线锚点。
- **不改变 NDI 音频透传，也不改变现场 PA 的声音**。增益不是“把现场声音调大”，也不能把已经削波的声卡信号救回来。
- 声卡原始峰值 ≥0.999 或增益后 ≥0.999 时，电平表上方常驻削波红灯，并区分「原始削波 / 增益削波」；表头同时显示原始峰值和补偿后峰值。
- 增益按「音源类型 + 设备名」分别记忆；换设备/换声卡不会沿用上一台的增益。
- 默认关闭、0 dB；不会自动追音量，避免破坏能量段落和 drop 判断。
- 输入连续偏小时，界面提示「输入偏小，可打开输入增益」。
- 音源选择提醒：**ASIO 只能抓 ASIO 设备本身，抓不到系统播放**；本机播放器出声请用「系统声音」，否则会出现“有声音但软件电平不动/认不出歌”的假故障。

## 二、Build Up（起歌段）

- 歌曲详情页新增「标记 Build Up」按钮。
- 点击后在波形上移动，显示 **32 拍（8 小节）洋红色段落**，起点自动吸附到八拍线。
- 波形上单击确定；双击已标记段落删除；点其他位置或按 Esc 取消。
- 标记保存在 `music_meta[path]["build_up"]`；演出时按歌曲识别位置触发，不依赖固定时间轴。
- 闪白节奏（按进入 Build Up 后的拍数）：
  - 第 1~8 拍：不闪；
  - 第 9~16 拍：每 4 拍一次；
  - 第 17~24 拍：每 2 拍一次；
  - 第 25~28 拍：每 1 拍一次；
  - 第 29~30 拍：每 1/2 拍一次；
  - 第 31~32 拍：抽空/不闪。
- 闪白只叠加在**最终输出画面**，不改素材本身，也不影响声音；CPU 合成路径和 GPU 多屏最终输出都会叠加。
- Build Up 段强制按「中动态」换一次素材池，结束后恢复原段落档位（通常是 drop 的高动态）。
- Build Up 段内跨段落边界不会额外换素材，避免在起歌段中间多切一刀。
- 1.3 修复：导入包里的 Build Up 现在能正常触发；`recognized_t=0` 时回退到当前段落秒数；停止播放/离开曲库试听时清掉残留闪白，不会在静止画面继续闪。
- 闪白混合改为快速原地混合，1080p 每帧约 1.6ms；旧 QPainter 整幅填白实测 4~8ms，在多屏下会明显拖帧。

## 三、ERLIB 曲库分析 / 导入包 / 工具集

- ERLIB 歌曲页新增 Build Up 标记，可随 `.eravjlib` **一起导出**；AutoVJ 导入后直接使用，不需要再手动标一遍。
- 修复数据库 `-wal/-shm` 或 db 文件只读导致 Build Up 保存失败的问题。
- 同一个音频同时出现在本机曲库和导入包时，**本机优先**；导入包同名重复项不再进入识别白名单，Build Up 只跟随可见的本地条目。
- 导入包中重复歌曲的 Build Up 不会再被直接丢掉：按文件名保留在 `skipped_build_ups`，再合并到本地歌曲 ID。
- 本地曲库与导入包走同一套合成器；区别只在 Build Up 元数据来源（`music_meta` / `imported_meta`），不会再出现“本地会闪、导入包不闪”的两套逻辑。
- FLAC 解码兜底：`soundfile` 报 `flac decoder lost sync` 时自动退回 PyAV；坏帧严重的文件仍需重新获取。
- ERLIB 工具集更新：ERLIB 改为单文件自解压版，带原图标；工具包内为 `工具集\ERLIB曲库分析.exe`，不再单独发布 ERLIB 附件。

## 四、GPU 多屏 / 输出 / 显示性能

- 多屏输出默认使用 **一屏一进程 GPU 合成**：每个屏幕独立图层、转场、LUT 和后处理，主界面预览、输出窗口、NDI / Spout 使用同一帧。
- 单屏输出仍走 CPU 合成；GPU 不可用、驱动异常或设置 `AUTOVJ_GPU_RENDER=0` 时自动回退 CPU，不黑屏。
- 主屏参数统一为全局设置：KV、自动/性能、颜色/后处理、节拍、模式/灵敏度在单屏和多屏之间共享；旧配置的主屏参数会自动迁移到全局。
- 每个独立屏仍保留自己的图层和颜色手动状态（`manual_t` 按屏保存），不会把主屏参数串到其他屏。
- NDI / Spout 共用同一张预乘 alpha 快照，去掉了渲染线程里重复的转换和整帧拷贝；单屏同时开 NDI+Spout 的 1080p 发送开销明显下降。
- alpha 画布改用预乘格式，避免每帧额外的透明通道转换；输出端仍保持正确的预乘 alpha 约定。
- 预览不再把整张 1080p 画面送到 GUI：主界面预览按 `ui.preview.res` 缩放（如 1/4 为 480×270），输出窗口单独拿显示帧。
- 显示定时器加密到 15ms，并按图像身份去重；输出状态页的卡片预览在演出时限制到 15fps，避免和主输出抢 CPU。
- 渲染分辨率严格等于输出设置：取消渲染精度/内部降采样，输出设置 1920×1080 就按 1920×1080 合成；显示器输出窗直接取原生帧，不再复用 `preview.res` 缩略图。
- 单屏演出台不再启动 GPU 一屏一进程渲染（它只返回低分辨率预览帧）；单屏直接 CPU 1:1 合成，输出窗取原生帧。
- 修复单屏输出窗盖住主窗后，引擎把主屏误判为“无人观看”而停止合成，导致输出黑屏、KV 层消失的问题。
- 图层增删卡顿修复：图层列表改为增量复用行，新增/删除只刷新必要的面板；实测新增约 30ms、删除约 5.5ms（旧版可能达到 1~10 秒）。
- 主界面预览在切歌、切配置、输出窗口重建时保持可见；修复预览停在旧帧/黑帧的问题。
- 手动图层（`auto_mode=False`）只响应「下一素材」按钮/快捷键和「播放此素材」，不再被段落、节奏、能量或 beat 自动切走。
- 修复单屏模式下 GPU 渲染进程未接管原生窗口时，显示器输出窗口被误隐藏、打不开的问题。
- 删除图层右键菜单里的「停止切换本层素材」「手动切换素材」入口，减少误操作。

## 五、EasyRealityCue 1.3

- 导出默认把素材一起打包，不再提供「是否内嵌」开关；超过 1GB 只提醒，不再阻止。

## 六、其它修复与兼容

- 单屏只使用主屏配置，不再混入其他屏幕图层；切回多屏时原配置恢复。
- 新建配置从空图层开始；复制配置保持完整复制。
- 浮动素材库退出多屏后保持打开；单屏配置下拉即时同步新建/删除/重命名。
- 配置下拉、控制条、箭头和底边框不再被裁切。
- 码表/曲库重复行、`fp_same` 旧映射、导入 4 首只显示 3 首等曲库显示问题继续修复。
- Build Up、段落切换、能量切换、颜色轮换共用八拍网格；没有段落表的歌仍按实测能量行为工作。
