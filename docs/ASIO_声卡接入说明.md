# ASIO 声卡输入 · 使用说明

> 适用版本：Easy Reality AutoVJ（2026.10.22 起 ASIO 按驱动可用性开放）
> 本机实测声卡：**Donner USB Audio Device**（2 路模拟输入）

---

## 一、先确认三件事

| 项目 | 怎么确认 |
|---|---|
| 驱动装了吗 | 软件里「设置 → 音频 → 音源类型」能看到 **ASIO（低延迟 · 声卡）** 且可选 |
| 通道有几路 | 选 ASIO 后，右侧「输入通道」下拉会列出 `Analogue 1 / Analogue 2` 之类 |
| 声卡在别处被占用吗 | 关掉 DAW、OBS、直播软件、语音软件（它们会独占 ASIO） |

本机探测结果（可直接对照）：

```
ASIO 驱动：Donner USB Audio Device
输入通道：Analogue 1（index 0）、Analogue 2（index 1）
实测参数：驱动默认 96000 Hz（软件按驱动报告值工作）｜ 缓冲 16 帧 ｜ 输入延迟 1.7 ms
自检脚本按 48000 Hz 申请时，驱动回报 48000 Hz / 8 帧 / 1.7 ms
```

> ⚠ 同一根 USB 声卡只有**一个 ASIO 实例**。软件在用时，别的程序打不开它，反之亦然。

---

## 二、在你的软件里接入（4 步）

1. 打开 **设置 → 音频**
2. **音源类型**选 `ASIO（低延迟 · 声卡）`
3. **设备**选 `ASIO: Donner USB Audio Device`
4. 右侧 **输入通道** 选：
   - 单声道麦/单路信号：`Analogue 1`（第 1 路）
   - 立体声（两路各接一个）：`Analogue 1` + `Analogue 2`
5. 点 **应用**（不点应用不生效）

生效后状态栏会显示一行：

```
[ASIO] 已开始采集：Donner USB Audio Device ｜ 通道 1/2 ｜ 96000 Hz ｜ 缓冲 16 帧 ｜ 输入延迟 1.7 ms
```

打开失败会自动**回退到系统声音**，并在状态区显示 `asio_failed` 的原因 —— 看到这句就说明没走 ASIO。

---

## 三、关键参数怎么设

### 1) 输入通道（ch0 / ch1）
- 软件按**两路**取：`ch0` 为左、`ch1` 为右
- 只接一路时，两路都指向同一路也能用（单声道内容）
- **选错通道 = 有画面没反应**：常见于把信号接在第 2 路却选了第 1 路

### 2) 采样率（Sample Rate）
- 以**驱动报告为准**。本机驱动默认 96000 Hz；软件会按驱动回报的采样率工作，不需要你改
- 想让 ASIO 固定 48 kHz：打开声卡自带的**驱动控制面板**（通常在任务栏托盘 / 开始菜单），
  把 Sample Rate 设为 48000，再回软件点「应用」
- 采样率**必须与驱动一致**：在驱动面板里改成 44.1k，软件却按 48k 打开 → 会报错或变调

### 3) 缓冲大小（Buffer Size / ASIO Buffer）
- 越小延迟越低、越吃 CPU；越大越稳、延迟越高
- 现场建议 **128~256 帧**（约 3~5 ms）；老机器用 512
- 本机实测 16 帧（0.2 ms）也能跑，但这是驱动的最小值，**不建议现场用**——
  一丝 CPU 抖动就会爆音（听感是"咔哒"）
- 改法同样在**驱动控制面板**里改，改完回软件重新「应用」

### 4) 与「系统声音（WASAPI Loopback）」的区别

| | ASIO | 系统声音（WASAPI） |
|---|---|---|
| 采什么 | **声卡的物理输入**（话筒/线路/CDJ） | **电脑正在播放的声音** |
| 延迟 | 1~5 ms | 20~80 ms |
| 能否抓别的软件播放 | **不能** | 能 |
| 适用 | 外部调音台/声卡送进来的音频 | 本机播放器、浏览器、DJ 软件 |

> 关键认知：**ASIO 没有 loopback**。想认"电脑里播的歌"，选系统声音；想认"调音台送进来的信号"，选 ASIO。

## 四、怎么验证输入真的被采集到

按顺序看三处，能快速定位问题在哪一层：

1. **软件状态行**：是否出现 `[ASIO] 已开始采集：...`
2. **电平**：设置页/状态区的输入电平条有跳动（有信号时 RMS 明显 > 0）
3. **识别是否工作**：播放一首库内歌（经声卡输入），状态从"未识别"变成歌名 + BPM

命令行快速自检（不需要开软件）：

```bat
venv\Scripts\python.exe tools\_asio_probe.py "Donner USB Audio Device"
```

会打印：驱动 / 实际采样率 / 缓冲帧 / 输入延迟 / 2 秒内的峰值电平 / 溢出次数。
峰值长期为 0.0000 ⇒ 信号没进来（先查线、增益、通道选择）。

## 五、常见问题与排查

| 现象 | 最可能的原因 | 怎么处理 |
|---|---|---|
| 「ASIO」灰掉不可选 | 没装驱动 / 软件没检测到 | 装声卡官方驱动或 ASIO4ALL；回设置页点「刷新」 |
| 打开报"被独占" | 别的程序（DAW/OBS/直播软件）占着 | 全部关掉，任务管理器确认无残留进程 |
| 状态显示已回退到系统声音 | ASIO 打开失败 | 看状态区的 `asio_failed` 原因；多为采样率不匹配或通道越界 |
| 有信号但软件里电平为 0 | 通道选错 / 增益为 0 / 线插在输出口 | 换「输入通道」；检查声卡增益旋钮；确认插的是 IN 不是 OUT |
| 声音断断续续、咔哒 | 缓冲太小 / CPU 抢占 | 驱动面板把缓冲调到 128~256；关掉软件里的高负载特效再试 |
| 认不出歌 | 选错音源类型（ASIO 抓不到系统播放） | 若音频来自本机播放器，改用「系统声音」 |
| 采样率不一致报错 | 驱动面板与软件设置冲突 | 以驱动面板为准，改完重新「应用」 |
| 插拔声卡后失效 | USB 重新枚举，句柄失效 | 重新选一次设备并「应用」（无需重启软件） |

---

## 六、现场建议（一句话版）

- **外部调音台/声卡送信号** → ASIO，缓冲 128~256，通道按实际接线选
- **本机播放器放歌** → 系统声音（WASAPI），不要用 ASIO
- 演出前用 `_asio_probe.py` 跑一次，确认"有电平、无溢出"，再点开始 VJ
