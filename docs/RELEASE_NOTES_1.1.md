# EasyReality AutoVJ 1.1 正式版

1.0 之后的修复版，重点是把单屏/多屏的关系和曲库重复导入理顺。

## 这一版修了什么

- **单屏只使用主屏配置**：单屏和多屏共用同一套输出配置；单屏只合成/解码主屏那份图层，其他屏幕的图层不再混进画面，也不会在后台继续解码。切回多屏时它们原样恢复。老配置主屏 `layers=None` 时，自动排除只属于独立屏的图层。
- **新建配置**：新配置从**空图层**开始，不再把原配置的图层带过来；之后新建的图层会自动归到当前主屏。复制配置仍完整复制当前配置。
- **单屏配置栏**：删掉多余的「应用」按钮（下拉即时生效）；「配置」按钮和下拉框各保留一个小箭头；多屏里新建/删除/重命名配置后，单屏下拉立即同步，删掉的配置不会再留在列表里。
- **控制条不再裁切**：取消单屏/多屏控制条的固定高度，交给布局按内容自然撑高，控件底边框不会被截；配置下拉右侧固定画一个居中小箭头（`ArrowComboBox`）。
- **浮动素材库**：退出多屏时不再自动关掉，开着的浮窗会保持打开。
- **曲库重复导入**：优先级固定为「本机 AVJ 曲库 > 导入的曲库分析包 > 码表」。本机刚导入、还没扫描时也能用文件名匹配，码表派生行不会再和本机行并排显示。`fp_same` 旧映射指向的文件如果已经不在当前曲库，不再用它隐藏码表行（修「导入 4 首只显示 3 首」）。

## 包

| 文件 | 内容 |
| --- | --- |
| `EasyRealityAutoVJ_1.1.zip` | 演出主程序（免安装） |
| `EasyRealityCue_1.0.zip` | 码表编辑器 |
| `EasyReality_Tools_1.0.zip` | ERLIB 曲库分析 + 音频发送端 + NDI 自检 + 音源诊断 |

解压覆盖即可。配置、素材库和码表数据在 `%LOCALAPPDATA%\AutoVJ`，不会被清空。
