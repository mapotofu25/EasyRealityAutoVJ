## 三、根因：为什么"感觉没效果"

| # | 根因 | 位置 | 性质 |
|---|---|---|---|
| 1 | 自动模式强度是**三层连乘**：`能量 × 0.6 × 全局强度`。全局强度 8% 时，E=0.5 只剩 **2.4%** | `engine.py` `_apply_postfx` | **主因**（用户当前设置正好踩中） |
| 2 | 手动锁色条件写成 `... and auto`：关掉「自动模式」后点色卡**永远无效**，而界面 tooltip 写着"关掉后只有点色卡才染色" | `colorfx.py:145` | 真 bug |
| 3 | `manual_t` 存的是 `perf_counter()`（进程内时钟）却被落盘 ⇒ 重启后 `now - t_manual` 为**负** ⇒ 一开机就被上次的颜色锁死（"颜色一直不变"） | `colorfx.py` + `ui_main.py` | 真 bug |
| 4 | `exposure` 默认 `level=0`，而手动模式有 `level>0` 的硬过滤 ⇒ 勾上「曝光脉冲」永远没效果 | `config.py` | 真 bug |
| 5 | 拖影 `reset_trails=not self.running`：**预览**（没点开始）时每帧都清缓冲 ⇒ 拖影永远为空 | `engine.py` | 真 bug |
| 6 | 色差 `shift=int(strength*14)`：强度 1~7 时 shift=0 ⇒ 滑条前 7% 是死区 | `postprocess.py` | 死区 |
| 7 | 频谱全 0（切音源时会置 `[0.0]*24`）时，频谱/变形仍走一遍全流程但什么都不画 | `postprocess.py` | 空转 |
| 8 | 码表接管返回时没清拖影缓冲，切回来可能闪一帧旧残影 | `engine.py` | 小 bug |
| 9 | `global_level` / `level` 的 0~1 与 0~100 两种尺度混用，写成 0.6 会被当成 0.6% | `engine.py` / `postprocess.py` | 健壮性 |

## 四、改了什么

| 文件 | 改动 |
|---|---|
| `src/engine.py` | 自动模式强度改为「全局强度感知曲线 `g**0.55` × 能量唤醒（0.15 以下 0、0.70 以上满）」；满滑块上限仍是 60%；拖影只在**停止那一帧**清一次；码表接管时清拖影；新增 `_postfx_info` 状态快照（10Hz）；`global_level` 0~1 尺度兜底 |
| `src/colorfx.py` | 手动锁色不再依赖 `auto`；锁定时刻改**墙钟**且要求 `0 ≤ 已过时间 < hold`（旧 perf_counter 值自动判过期）；中低能量强度 0.20~0.40 → **0.35~0.60**；升速 0.14 → 0.24（约 0.15 秒到位） |
| `src/postprocess.py` | 色差低强度不再归零（最少 1px）；频谱/变形在频谱全 0 时短路；新增 `_level01()` 兼容 0~1 尺度 |
| `src/config.py` | `exposure` 默认 level 0 → 30 |
| `src/ui_main.py` | 后处理页新增**实时强度回显**；`manual_t` 写墙钟；回填色卡高亮同口径判过期；自动模式提示文案更新 |
| `src/i18n_map.py` | 补 15 条中英词条（含之前漏译的 ASIO 提示），覆盖度检查 **✅ 无残留** |
