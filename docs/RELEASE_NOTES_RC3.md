# ERAVJ RC3（2026.10.22）

> Easy Reality AutoVJ —— Windows 免费开源的自动 VJ 软件。
> 本版相对 RC1 的主要变化：**认歌防误报、ASIO 回归、码表 GIF 修复**。

## 修复

- **误识别（把库外歌认成库内歌）**：指纹库会残留已从曲库移除的历史条目，匹配器照常返回它们。
  现在只允许「当前曲库 + 导入曲库 + 码表曲目」的 song_id 参与匹配，并加「单拍峰值 ≥80 票」门槛。
  实测：库外 40 首随机样本 **0 误认**（此前 5%）。
- **指纹 id 错位**：历史扫描若路径写法变过（`W:\` 与 `W:/`），同一首歌会存成旧 id，
  表现为「哈希全命中、票数 0」。新增启动自愈：仍在曲库里的歌，按票数≥100 且 offset 吻合自动改挂。
- **码表位置偏快约 2 秒**：识别层曾加 +1.5s 采集补偿，与码表层已有的 0.5s 提前量叠加。
  现在识别层补偿默认 0.0，可用 `AUTOVJ_REC_LATENCY` 微调。
- **码表里的 GIF 一直卡在第一帧**：GIF 播放器没有 `position()`，且「到出点冻结」的早返回
  会把第一帧永久缓存。GIF 现在不参与冻结，保持循环播放。
- **ASIO 打开失败时无任何提示**：现在音频面板会显示 `✅ ASIO 已启用：…` 或
  `⚠ ASIO 打开失败：<原因>（已回退到系统声音）`。

## 新增 / 调整

- **ASIO 重新开放**（按驱动可用性）：有驱动即可选，无驱动则灰掉并提示装驱动。
  实测 Donner USB Audio：96 kHz / 16 帧 / 1.7 ms。
- **麦克风 / 线路输入分离**：两者共用 WASAPI 通道，但设备列表按端点类型过滤，不再显示成一样。
- **码表页改为左右分栏**：左列表、右详情，点一行直接看，不再弹独立窗口。
- 删除「输出」里「Spout 只传画面，不含音频…」提示；删除码表详情里多余的层属性入口。

## 已知限制

- 同一录音在曲库与导入库各存一份时，锁定到的 song_id 可能是另一份（歌名/时长一致，属目录重复）。
- 「无指纹」素材无法用本机曲库验证（本机语料最低覆盖率仍有 0.66），改用合成音频回归：白噪/静音/扫频/方波 4/4 不误认。
- 导入曲库与本地文件的对账仍依赖文件名，重命名会失配。

## 安装

解压即用（免安装）。首次启动会在 `%LOCALAPPDATA%\AutoVJ` 建配置与索引。
