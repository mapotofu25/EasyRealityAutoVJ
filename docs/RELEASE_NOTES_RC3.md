# ERAVJ RC3（2026.10.22）

> Easy Reality AutoVJ —— Windows 免费开源的自动 VJ 软件。
> 本版相对 RC1 的主要变化：**认歌防误报、ASIO 回归、码表 GIF 修复**。

## 修复

- **误识别（把库外歌认成库内歌）**：指纹库会残留已从曲库移除的历史条目，匹配器照常返回它们。
  现在只允许「当前曲库 + 导入曲库 + 码表曲目」的 song_id 参与匹配，并加「单拍峰值 ≥80 票」门槛。
  实测：库外 40 首随机样本 **0 误认**（此前 5%）。
- **指纹 id 错位**：历史扫描若路径写法变过（`W:\` 与 `W:/`），同一首歌会存成旧 id，
  表现为「哈希全命中、票数 0」。新增启动自愈：仍在曲库里的歌，按票数≥100 且 offset 吻合自动改挂。
- **码表位置偏快约 2 秒**：识别层曾加 +1.5s 采集补偿，与码表层已有的 0.5s 提前量叠加。
  现在识别层补偿默认 0.0，可用 `AUTOVJ_REC_LATENCY` 微调。
- **码表里的 GIF 一直卡在第一帧**：GIF 播放器没有 `position()`，且「到出点冻结」的早返回
  会把第一帧永久缓存。GIF 现在不参与冻结，保持循环播放。
- **ASIO 打开失败时无任何提示**：现在音频面板会显示 `✅ ASIO 已启用：…` 或
  `⚠ ASIO 打开失败：<原因>（已回退到系统声音）`。

## 新增 / 调整

- **ASIO 重新开放**（按驱动可用性）：有驱动即可选，无驱动则灰掉并提示装驱动。
  实测 Donner USB Audio：96 kHz / 16 帧 / 1.7 ms。
- **麦克风 / 线路输入分离**：两者共用 WASAPI 通道，但设备列表按端点类型过滤，不再显示成一样。
- **码表页改为左右分栏**：左列表、右详情，点一行直接看，不再弹独立窗口。
- 删除「输出」里「Spout 只传画面，不含音频…」提示；删除码表详情里多余的层属性入口。

## 已知限制

- 同一录音在曲库与导入库各存一份时，锁定到的 song_id 可能是另一份（歌名/时长一致，属目录重复）。
- 「无指纹」素材无法用本机曲库验证（本机语料最低覆盖率仍有 0.66），改用合成音频回归：白噪/静音/扫频/方波 4/4 不误认。
- 导入曲库与本地文件的对账仍依赖文件名，重命名会失配。

## 安装

解压即用（免安装）。首次启动会在 `%LOCALAPPDATA%\AutoVJ` 建配置与索引。

# 修复包（2026.10.23.02）

> 针对「颜色渲染 / 后处理看不出效果」。逐项验证报告见
> `docs/颜色渲染与后处理验证_20261023.md`。

## 修复

- 【修复】后处理自动模式强度是三层连乘（能量 × 0.6 × 全局强度），全局强度调到 8% 时
  实际只有 2%~5%，肉眼等于没有。改为「全局强度感知曲线 × 能量唤醒」，同样设置下强度提升 3.5~4.7 倍。
- 【修复】关掉「自动模式」后点色卡完全没有反应（代码多了一个 `and auto` 条件，和界面说明相反）。
- 【修复】重启软件后颜色被上一次点的色卡永久锁死（锁定时刻存的是进程内时钟，重启后差值为负）。
- 【修复】「曝光脉冲」手动模式下勾上也没有效果（默认强度是 0，而手动模式以「强度 > 0」为前提）。
- 【修复】预览状态下「拖影」永远看不到（未点开始时每帧都清空残影缓冲）。
- 【修复】「色差」强度 1~7 整段无效果（位移取整后为 0）。
- 【修复】码表接管切回来时可能闪一帧上一场的拖影残影。
- 【修复】`global_level` / 单个效果强度写成 0~1 小数时（老配置）会被当成 0.6% ⇒ 静默失效。

## 新增

- 【新增】后处理面板底部实时显示当前生效的效果与强度，例如
  `后处理（自动）：辉光 39% · 色差 39%`；被码表/Kv 接管或总开关关闭时直接写明原因。
- 【新增】颜色渲染状态行区分「能量过低，颜色渲染已休眠」与「手动锁定」，并显示剩余秒数。

# 素材切换（2026.10.25.01）

## 调整

- 【调整】素材右键菜单「固定为本层素材」→ **「停止切换本层素材」**（已经停住时显示
  「恢复切换本层素材」）。图层右键菜单里同名的那一项也一并统一，两处口径一致。
- 【新增】**「手动切换素材」**（图层右键菜单）：按一下顺序切到本层的下一个素材。
  只动这一层，**不重排全局切换倒计时**，不会把别层的节奏打乱。
  （素材右键菜单里**不放**这一项：那里的「播放此素材」已经能把本层切到任意一格，
  再挂一个"顺移下一个"是重复 —— 用户指出后已删。）
- 【新增】「素材切换节奏」下拉加回 **「手动（不自动切换）」**：选它之后永远不自动换素材，
  只在「手动切换素材 / 播放此素材 / 下一素材快捷键」时才换。

## 边界（用户明确要求，已逐条实测）

- **码表图层**：不受影响 —— 画面仍由 `.ercue` 运行时驱动（实测手动模式下码表驱动照常每帧进）。
- **Kv 待机层**：不受影响 —— 仍由静音进出驱动；「手动切换素材」对 Kv 图层**拒绝执行**。
- **已「停止切换」的图层**：不会被自动切换顶掉；手动切换它时，`fixed` 跟着挪到新素材
  ⇒ **切完仍然是停住状态**。
- 全局「锁定画面」时，手动切换同样拒绝执行。

## 实测

- 真机（打包 exe + 真放音频 40 秒，读 `layer_health.log` 的 `cur=`）：
  手动模式素材序号恒为 `[0]`（一次没换）；切回自动模式同条件跑遍 `[0..7]`。
- 离屏回归 `tools/_test_manual_switch.py`：24 项全通过（含 Kv/码表/锁定/单素材/越界/回绕/
  fixed 跟随/切回自动恢复/`MODES` 不含 manual 防 KeyError）。
