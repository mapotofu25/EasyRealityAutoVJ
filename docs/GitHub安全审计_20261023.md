## 三、逐项处理建议

### 1）固定演出端依赖（P1）

```text
# requirements.txt 建议改为
PySide6==6.11.2
numpy==2.5.3
SoundCard==0.4.6
opencv-python==4.10.0.84
soundfile==0.14.0
av==18.1.0
glfw==2.10.2
```

更稳的做法：用 `pip freeze > requirements.lock.txt` 生成锁文件，CI/打包只认锁文件。
（以上为本机 `pip freeze` 实测值。）

### 2）给 `main` 加分支保护（P1）

GitHub → Settings → Branches → Add branch protection rule：
- 勾选 **Require a pull request before merging**（至少 0 个审批，防直接推）
- 勾选 **Do not allow force pushes**
- 勾选 **Do not allow deletions**

单人开发可只开后两项，不影响日常提交。

### 3）删除嵌套重复目录（P2）

在本地仓库执行（已确认与根目录重复）：

```bat
git rm -r --cached EasyRealityAutoVJ
rmdir /s /q EasyRealityAutoVJ
git commit -m "chore: 删除与根目录重复的嵌套源码目录"
git push
```

> 若担心历史仍在，可后续用 `git filter-repo` 清理历史；但目录内**无凭据**，不清理也可接受。

### 4）清理本地路径/用户名（P2）

- 一次性诊断产物（`audio_probe.txt` 等）直接删除，不要入库；
- 脚本里的绝对路径改为相对路径或环境变量：
  ```python
  BASE = os.environ.get("ERAVJ_HOME", os.path.dirname(os.path.dirname(__file__)))
  ```
- 批量检查命令：
  ```bat
  git grep -nE "[A-Za-z]:\\\\?Users\\\\?[A-Za-z0-9_.-]+|[A-Za-z]:[\\\\/]ERAVJ[\\\\/]"
  ```

### 5）将来加 CI 时的安全基线（P3）

- Settings → Actions → General：把 **Workflow permissions** 设为 *Read repository contents*；
- 只允许官方 `actions/*` 与你信任的 Action，并 **pin 到 commit SHA**；
- 需要发布时用 `GITHUB_TOKEN` 的最小权限（`contents: write` 仅发布 job）。

### 6）联系方式（P3，可选）

若不想被爬虫抓取，把 QQ/群号改成「见 README 的加群链接」或图片；保留也属正常开源项目做法。
