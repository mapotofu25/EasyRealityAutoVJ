# EasyReality AutoVJ 1.2 Beta2

## Build Up 闪白

- 歌曲详情页新增「标记 Build Up」按钮。
- 点击后在波形上移动，显示 **32 拍（8 小节）洋红色段落**，起点自动吸附到八拍线。
- 波形上单击确定；双击已标记的段落删除；点其他位置或按 Esc 取消。
- 标记保存在 `music_meta[path]["build_up"]`，演出时按歌曲识别位置触发。
- 同一个音频如果同时在本机曲库和导入包里（不同 `song_id`），**本机优先**：导入包同名重复项不再进入识别白名单，识别会回到本机 ID；Build Up 也只跟随曲库管理里可见的本地条目。
- **Build Up 段强制按中动态处理**：进入这 32 拍时重新按中动态换素材池，结束后恢复原段落档位（通常是 drop 的高动态）。

## 闪白节奏

按 Build Up 剩余拍数渐快，不是整段都闪：

- 前 8 拍：不闪；
- 第 9~16 拍：每 4 拍闪一次；
- 第 17~20 拍：每 2 拍闪一次；
- 第 21~24 拍：每 1 拍闪一次；
- 第 25~32 拍：每 1/2 拍闪一次。

闪白只叠加在输出画面，不改素材本身，也不影响声音。

## 音频解码兜底

- soundfile 读不了的 FLAC（`flac decoder lost sync`）自动退回 PyAV；坏帧严重的文件仍需重新获取。

## GPU 纹理合成（绑定「GPU 解码」）

- `GPU 解码` 打开时，主屏走新的 OpenGL 纹理合成器；关闭时仍走原来的 CPU QPainter 路径。
- 当前支持普通图层：视频/图片纹理、cover、缩放、旋转、透明度、普通 SourceOver、alpha。
- 遇到码表正在播放、转场、特殊混合、输出 alpha 时自动回退 CPU，不黑屏。
- 旧的 `gpu_compose`（FBO 回读的假 GPU）不再与 GPU 解码同时启用，避免 11fps。
- 首次合成会编译 shader，可能有一次短暂启动延迟。
