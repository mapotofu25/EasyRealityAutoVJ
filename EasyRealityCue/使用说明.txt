EasyRealityCue —— DJ 码表（Cue Sheet）编排编辑器
版本 2026.10.22.06
（上面这行的版本号在每次打包时由 tools\build_version.py 自动改写，无需手改）

一、这是什么
  EasyRealityCue（简称 ERC）是一个给 DJ 用的「码表编排编辑器」。
  你用它在电脑上给一首歌排好：什么时间点、哪一层、显示哪段画面、怎么混、怎么进怎么出，
  然后导出成一个 .ercue 文件，交给演出端去放。
  它是**纯编排（Authoring）工具**：不做实时演出播放，不播 DXV，不做 NDI / Spout / GPU 输出。
  预览走纯 CPU 渲染，对显卡没有特殊要求。

二、怎么启动
  1. 把整个压缩包**完整解压**到一个目录（EasyRealityCue.exe 与 _internal 文件夹必须放在一起，
     不能只把 exe 单独拷走）。
  2. 双击 EasyRealityCue.exe 即可运行。免安装，无需预装 Python。
  3. 配置（最近打开的文件、上次使用的目录）保存在
     %LOCALAPPDATA%\EasyRealityCue\config.json，不写注册表；删掉该文件即恢复默认。

三、界面分区
  顶栏     ：当前码表[下拉] ｜「码表 ▾」菜单（新建… / 导入… / 导出当前码表… /
             打开最近 / 关闭）｜ 撤销 / 重做 ｜「导出当前码表」[最右，强调色]
  状态行   ：码表：X（共 N 张）　曲目：Y　层数：N　位置：T
  左上 4 个标签页：
    ① 码表包   —— 管理多张码表：新建 / 导入 / 导出 / 删除（只从列表移除）/
                  指定素材目录…
    ② 曲目     —— 一首歌一条。加曲目、导入音频（自动读标签与时长）、编辑曲名 /
                  艺术家 / 时长 / BPM；选中哪首就编排哪首。
    ③ 素材     —— 这张码表用到的视频 / 图片。双击 = 在播放头位置给当前层加片段；
                  可拖到时间轴；右键 = 在文件管理器里定位 / 从这张码表里去掉。
    ④ 片段属性 —— 选中片段的全部参数（见下）。
  右上     ：预览（这首歌 + 这张编排）+ 传输条（⏮ 回到开头 / ▶ 播放 / 循环 / 位置滑杆）
  下方     ：时间轴（横轴 = 时间，单位秒）+ 工具条（＋层 / 删除层）
             时间轴下方：「显示素材音轨」开关（默认关；勾上后在片段块内画出该素材的音轨波形）
  底部     ：日志（只读，记录每一步操作与警告）

四、基本操作流程
  1. 新建码表：「码表 ▾ → 新建…」，或「① 码表包 → 新建…」。弹窗里填**码表名**并选
     **画布比例**（16:9 / 9:16 / 4:3 / 3:4 / 自定义宽高）；比例决定预览画布与导出画面的比例，
     随时可在状态与预览上看到效果（默认 16:9 = 1920×1080）。
  2. 加素材：「③ 素材 → ＋ 素材…」选视频 / 图片（可多选）。
     · 只记路径，**不拷贝文件**；列表里显示缩略图，文件找不到的会标红「（丢失）」。
     · 素材换过位置：用「指定素材目录…」按同名文件递归重挂。
     · **图片**放到时间轴上默认**占 5 秒**（可在片段属性里改时长）。
  3. 加曲目：「② 曲目 → ＋ 曲目」建一条，再「导入音频…」——用音频标签里的
     曲名 / 艺术家 / 时长自动填。导入音频后会**在后台自动**算两个认歌用的身份（面板上可见，
     不影响操作）：**「文件 md5」**（同一文件最可靠）与**「指纹 id」**（音频指纹签名，
     改名/换目录也能认出来）；此外「曲名 + 艺术家 + 时长」会归一化成 meta key 参与认歌。
     · 【新增】**BPM 会自动识别**：导入音频后软件在后台听一遍算出 BPM（面板上可见，不影响
       操作）；也可以随时点 BPM 输入框右边的**「自动识别」**手动重算（按钮变「识别中…」期间
       请稍等，完成后日志会记下「原值 → 新值」）。**自动识别不会覆盖你手填的 BPM**，
       只有手动点「自动识别」才会覆盖。
     · 【新增】**优先用 VirtualDJ 曲库里的 BPM**：本机装了 VirtualDJ 且有这首歌的分析记录时，
       直接采用它的 BPM（状态行会写「来自 VirtualDJ」，这就是演出端在用的值），又快又准；
       库里没有这首歌才现场听音频分析（状态行会写「音频分析，建议核对」—— 实测约 2/3 命中，
       可能偏 1~6 BPM，鼠标悬停 BPM 框会列出**备选候选**，供你判断是不是半速/双速）。
     · 【修复】**BPM 是可选填的，不填也能正常演出**：片段位置取自原曲播放秒数，
       两端的拍↔秒换算用的是同一个系数、比较时互相抵消 ⇒ **BPM 填错、留空、
       一首歌里有多段 BPM，都不会让画面对不上**。BPM 只影响「按小节查看 / 对齐」，
       以及导出前的提示（只是提醒，不阻止导出）。识别失败时状态行写「BPM 没识别出来
       （可以留空，不影响演出）」。
     · 【修复】导出时不再把**编排端自己的版本号**写进「要求演出端最低版本」
       （那会导致演出端每次导入都误报「这张码表要求 X 以上版本（当前 X-1）」）。
     · 【修复】「指纹 id」改为按**源文件原生采样率**计算（与演出端同口径）；
       ⚠ **本版本之前导出的码表里 `fp_id` 是旧口径算的**（48k 源的歌在演出端对不上）
       ⇒ 升级后请对相关曲目**重新扫描身份并重新导出**。
  4. 排片段：把素材**双击**（加到播放头位置）或**拖到时间轴某一层**上。
     · 新建曲目默认给一层；可「＋ 层」加层。层号越大越靠上（后画的盖住先画的）。
     · 片段可整体拖动平移（保持时长）、跨层拖动；**双击**片段进入**剪辑态**后拖左右把手
       可改入点/出点（trim 开头/末尾）；删除用 **Delete 键**或**右键菜单 → 删除片段**
       （只删这一段，不会删素材文件）。
  5. 调属性：选中片段后到「④ 片段属性」改：
     素材 / 起点 / 时长 / 入点 / 出点 / 入场（淡入·硬切·滑动·缩放·故障）+ 入场时长 /
     出场 + 出场时长 / 变速（滑条 / 输入框，二者双向同步）/ 画面裁切（X Y W H）/ 大小 / 位移 /
     本素材混合（常规·添加·屏幕·多层·变亮·变暗·减少）/ 本素材不透明度 / 备注。
     · 选中片段时，最后两项「本素材混合」「本素材不透明度」改的是**这一段素材**；片段没设过
       就显示「继承本层」，把混合下拉选「（继承本层）」、或勾上「继承本层」，即可撤销覆盖、
       改回跟随本层。没选中片段时，这两项改的是当前**层**（标签显示「本层混合 / 本层不透明度」）。
  6. 预览：按 ▶ 播放；导入了音频则**由音频走带**驱动，否则用挂钟推进。
     「循环」勾上则播到结尾自动从头再来；拖「位置」滑杆或按 ⏮ 可任意定位。
     · **选中片段后可直接在预览上拖动画面**改位移、**滚轮**缩放；松手才生效（可一次撤销）。
       注意：位移一变，该片段就从「铺满(cover)」转为「完整显示(contain)」（画布左上角有角标提示）；
       想回到铺满，用**右键菜单 → 重置画面变换**。
     · **选中片段后双击预览**进入**裁切模式**：画面上出现裁切框与**四角 / 四边共 8 个把手**，
       拖把手即可改该片段的**画面裁切**（源归一化 X/Y/W/H），**松手才生效**（可一次撤销）；
       **Esc** 或**再次双击**退出裁切模式。
     · **点预览的空白处**（比例框外，或画面外的黑边）⇒ **取消当前选中**（片段属性面板与预览
       选中状态一并清空）；点在画面上仍是拖动位移，不会取消。
  7. 导出：「码表 ▾ → 导出当前码表…」「① 码表包 → 导出…」，或**右上角「导出当前码表」按钮**，导出为 .ercue。
     · 导出前会做检查，清单显示在弹窗与日志里：
         -【缺素材】会**阻止导出**（默认焦点在「取消」，也可选「仍然导出」）；
         -【超长】片段落点超出曲目总长，或时长超过素材本身。
     · 「把素材一起打包进 .ercue」默认**关闭**；勾上则内嵌素材（**没有体积上限**，
       超过 1 GB 会弹窗提醒、由你选择是否继续内嵌）。
     · 【新增】导出会自动把**用到的素材缩略图**放进包内 `thumbs/<clip_id>.png`
       （长边 ≤256、保留透明度；后台生成带进度条、不卡界面；同一素材第二次导出走缓存）。
       导出成功的弹窗会写「已带 N 张缩略图」。演出端没有这些图也能正常工作。
  8. 自动保存：编辑停顿约 1.5 秒会**自动保存到独立目录**（`%LOCALAPPDATA%\EasyRealityCue\autosave\`），
     下次打开自动恢复上次的工作区；**绝不**改写你的 .ercue。关闭时若有改动未导出，会给一句
     **非阻断**提醒（默认「跳过并退出」）；想改可到配置里关掉该提醒。

五、时间轴与快捷键
  · 鼠标滚轮 = 上下滚动；Shift+滚轮 = 水平平移；Ctrl+滚轮 = 缩放；Alt+滚轮 = 调行高。
  · 片段交互：**单击**选中（不再直接进入拖动，避免误拖）；**双击**进入**剪辑态**
    （左右把手 = trim 开头/末尾，拖中部 = 整体平移；Esc 或单击空白退出）；
    **右键**弹菜单：属性 / 复制片段 / 重置画面变换 / 定位素材 / 删除片段；
    **Delete 键** = 删除选中片段（只删片段，不删素材文件）。
  · 「显示素材音轨」开关：勾上后，视频素材的音轨波形会画在**片段块内**（后台分析，不卡界面）。
  · Ctrl+Z 撤销，Ctrl+Shift+Z 重做（每张码表独立，最多 50 步）。

六、常见问题
  · 打开别人给的 .ercue 提示"有素材没找到"？
    说明对方导出时没有内嵌素材，而你机器上没有这些文件。用「指定素材目录…」指向素材
    所在目录按同名重挂；也可以先「用占位色块先跑」——缺失片段在预览里会被跳过，
    编排照常可以编辑和导出。
  · 按 ▶ 按钮显示"准备中…"、点了没反应？
    音频正在后台解码（不卡界面），就绪后再按一次即可。
  · 关闭软件会残留后台线程 / 句柄吗？
    不会。关闭时会停掉音频线程、缩略图线程、身份扫描线程、素材音轨波形线程并释放全部解码器。

八、给维护者的打包注记
  · 版本号：由 tools\build_version.py 生成（日期 + 当日序号，如 2026.10.01.06），
    打包时自动写进 src\ercue\_build_ver.py，界面与导出文件里的版本号都读它。
  · 打包：venv\Scripts\python tools\build_exe.py → tools\make_zip.py → tools\smoke_exe.py。
  · ★ 包内的 `_internal` 里有一份 `tools\smoke_hook.py`（PyInstaller runtime-hook），
    这是**正常的、有意保留的**，不是遗留垃圾：它默认什么都不做，只有在环境变量
    `ERCUE_SMOKE=1` 时才会在启动后跑一段自检（给 tools\smoke_exe.py 用）。
    正常双击运行不受任何影响。
