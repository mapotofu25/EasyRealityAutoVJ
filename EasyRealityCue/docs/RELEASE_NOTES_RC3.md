# EasyRealityCue RC3（2026.10.22）

> ERAVJ 的附属软件：给每首歌排码表（什么时候切画面、切哪段、怎么进怎么出），
> 导出 `.ercue` 交给演出端执行。

## 新增

- **GIF 素材支持**
  - 选材对话框加入 `*.gif`（此前选不到）。
  - GIF 按视频同样处理：可变速、可**掐头去尾**（旧限制「GIF 不得设出点」已解除）。
  - **拉长自动循环**：把片段拉长超过素材时长时，源出点保持不变，多出来的长度由循环填充
    （视频仍是「到出点冻结」，行为不变）。
- **缩略图缓存按路径**：此前同一 `clip_id`（每张码表都从 `c1` 编号）会被跨码表复用，
  换码表后显示上一张码表的图；现在键为素材路径（含 mtime）。

## 修复

- **GIF 预览内容一闪一闪**：预览取帧的「seek + 复用上一帧」路径对 GIF 会返回第 0 帧/陈旧帧
  （实测 40 个采样点里 24 个错帧）。现在 GIF 走精确取帧 + 全帧缓存（≤80 帧），
  实测 **0 错帧**、**0.2 ms/帧**（原 20~28 ms）。
- **属性面板冗余**：未选中片段时不再显示「本层混合」「本层不透明度」，
  只保留选中素材才出现的属性。

## 已知限制

- 超长 GIF（>80 帧）不缓存，走精确解码，预览可能略慢。
- 改变速时片段长度会按「变速一致性」重新收敛一次（防音画不同步的既有保护）。
