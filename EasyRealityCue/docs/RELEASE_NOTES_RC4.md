# EasyRealityCue RC4（2026.11.08）

> 码表编辑与演出端 —— 给 AutoVJ 用的逐曲码表工具。
> 本版相对 RC3 的主要变化：**左侧四段改可折叠竖排**、**「相邻同设置」合并成 run**、
> **转场不再用素材自身几何**。

## 界面

- 左侧四个区块（码表 / 素材 / 层 / 属性）从固定的 `QTabWidget` 改成**可折叠竖排**，
  默认全部展开 —— 演出中一屏能看到全部信息，不用来回切页签。
- 属性面板再精简：只留真正要改的项；图片 / GIF 的默认时长与帧率合并到一处。
- 主题样式整理（面板间距、按钮最小高度统一）。

## 时间轴 / 转场

- **「相邻同设置视为一个素材」(run)**：同一层上连续几段用同一个素材、同一套设置时，
  按一个整体处理 —— 修掉「GIF 吸附紧挨时仍然先切出再切入」的闪帧。
- **转场忽略素材自身几何**：缩放 / 淡出 / 滑动一律相对**画布**计算，
  不再跟着素材原始分辨率走（修「缩小图淡出变全屏」「滑动从屏幕最右边进来」）。
- 时间轴吸附与片段边界的不变量测试补齐（改 BPM 不移动片段）。

## 媒体

- 素材探测（`media/probe.py`）与取帧（`media/frames.py`）重写：
  统一走 PyAV，GIF 与静态图走同一套默认时长逻辑。
- 预览渲染（`render/compositor.py`）与预览窗口的同步修正。

## 导入导出

- 读包以「秒」(`at_sec`) 为权威，拍 (`at_beats`) 降为派生 —— 与演出端同一口径。
- 导出包内继续带 `thumbs/<clip_id>.png` 缩略图与 `fp/<fp_id>.bin` 指纹序列。

## 仓库卫生

- 开发探针、回归截图、内部审计记录移出版本库；源码注释里的本机绝对路径换成占位符。
- 依赖钉死版本（`requirements.txt`）。

## 安装

解压即用（免安装）。需要 Windows 10/11 x64。
