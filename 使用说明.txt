Easy Reality AutoVJ 使用说明
=============================
版本 2026.10.01.09
把音乐变成画面的实时自动 VJ 引擎

本说明按「从装好到上台」的真实顺序写。第一次用建议照着一路读下来。


────────────────────────────────────────
界面总览（左上角三个页签，随点随切）
────────────────────────────────────────
整个软件分成三个界面，共用同一套画面引擎与同一批素材，左上角页签常显：

  🎬 演出台        现场用：图层 + 预览 + **素材库** + 效果设置 + 输出设置
  🗂 素材库        演出台那份素材库的**全屏副本**：搜索 / 筛选 / 导入 / 打标签
  🎵 曲库 · 曲风    演出前准备：音乐曲库（导入音乐 + 扫描分析曲风）/ 曲风映射

· **素材库在演出台上也有一份**（和预览并排）——现场随时取素材、**直接拖进图层**；
  双击缩略图 = 立即播放到当前图层（更快）。
· 第 2 个页签是同一个素材库的**全屏版**：同一批素材，搜索和筛选状态两边同步，
  适合导入一大堆素材时慢慢整理。
  ⚠ **「拖进图层」只能在演出台做**（跨页面拖拽系统不支持）。
· 顶部工具条的「🎵 音乐曲库 / 曲风映射」已收进第 3 个页签。
· 下次启动会**停在上次那个界面**。
· 顶部工具条（▶ 开始 / 黑场 / 冻结 / 暂停自动 / 下一素材 / 音源 / GPU 解码）
  在三个界面**都常显**，现场操作不受影响。
· 右上角「⋯ 更多」里收着：主题、语言、快捷键、关于。


────────────────────────────────────────
一、安装与启动
────────────────────────────────────────
1. 把整个文件夹解压出来（不要只拿 EasyRealityAutoVJ.exe）。
   exe 旁边的 _internal 文件夹是程序本体的一部分，缺了打不开。
2. 双击 EasyRealityAutoVJ.exe 启动。
   首次启动 Windows Defender 会扫描一遍，可能要等十几秒到一分钟，属正常。
3. 启动后右下角如果出现「正在扫描素材库」，说明软件在重算素材标签，
   等它跑完即可（有进度显示，不会卡死）。

提示：整个文件夹可以放 U 盘或任意盘，路径里有中文也没问题。
      但别放在需要管理员权限的目录（如 C:\Program Files）。


────────────────────────────────────────
二、上手流程
────────────────────────────────────────
第 1 步：选音源
  点顶部「🎛 音源」，选「系统声音」，这样软件能听到你电脑正在放的音乐。
  （如果你用外置声卡 / DJ 控制器，也可以选「线路输入 / 声卡」）

  ▼ 追求更低延迟时选「ASIO（低延迟）」
    ⚠ **此功能尚未完成，当前仅供测试**（界面上该项也标了「未完成」）。
    下面的说明只是告诉你它打算怎么做，正式用请暂时仍选「系统声音」。
    ASIO 绕过系统混音器直连声卡驱动，实测延迟可到 **11 毫秒**（WASAPI 一般 20~60 毫秒），
    逐拍切换、频谱瞬态会跟得更紧。
    · 下拉里列出的是**声卡驱动**（装了驱动才有，比如声卡自带 / DJ 控制器自带的那份）；
      没有 ASIO 驱动时这一项是灰的，鼠标停上去会说明原因。
    · ⚠ **同一个 ASIO 驱动同时只允许一个程序用**。VirtualDJ / 宿主机（DAW）正开着的时候
      会连不上 —— 这时软件会**自动改用系统声音**并在界面上提示，不会没声音。
      想让 ASIO 生效就先把占用它的程序关掉，再点一次「应用」。
    · ⚠ ASIO 的采样率是驱动全局的，软件**不会**去改它（免得影响 VDJ 那边），
      所以选 ASIO 时「采样率」那一栏是灰的。
    · 用外置声卡/控制器时，用**它自带的那份 ASIO 驱动**效果最好；
      主板自带的 ASIO（如 Realtek ASIO）延迟和稳定性一般。

第 2 步：导入素材
  点「导入文件夹」或「导入文件」，把你的视频 / 图片素材装进来。
  支持 mp4 / mov / webm / avi / mkv / gif / png / jpg / webp 等。

第 3 步：扫描打标（很重要，别跳过）
  素材进来后，点素材库上方的「扫描打标」。
  软件会用本地 AI 给每个素材打上内容标签（蓝色 / 粒子 / 海洋……）
  和动态标签（低动态 / 中动态 / 高动态 / 频闪）。
  没有标签的素材，自动匹配时基本挑不到它 —— 这一步直接决定配画面准不准。
  打标是后台跑的，可以边打边用，中断了下次会接着扫。

第 4 步：新建图层，并选前景或背景
  点图层区右上角的「+ 图层」，选「自动（按曲风匹配画面）」或「手动」，
  然后选角色：
    · 背景：铺满全屏的环境画面（打底）
    · 前景：黑底或带透明通道的叠加元素（光效、特效）
  一般两张都建：一张背景打底 + 一张前景叠加，画面层次最好看。

第 5 步：先扫描音乐曲库（强烈建议，演出前做完）
  点第 3 个页签「🎵 曲库 · 曲风」→「🎵 音乐曲库…」，导入音乐文件夹，点「扫描分析」。
  软件会逐首建指纹并识别曲风（后台、可续扫，扫一次以后一直有效）。
  扫过之后，现场放歌时它才能识别出「这首歌是什么曲风」，
  从而挑对应风格的画面；没扫的话只能用实时估算的曲风兜底，准确度差一截。

第 6 步：点「开始自动 VJ」
  画面就会跟着音乐自动切换了。
  想看全屏效果，点「显示输出窗口」，把它拖到第二块屏幕上全屏。

搞定。剩下的都是调优，慢慢看。


────────────────────────────────────────
三、音源设置
────────────────────────────────────────
· 音源类型
    系统声音（WASAPI Loopback）：采集电脑播放的声音（DJ / VJ 现场最常用）
    麦克风：采集话筒输入（适合对着音箱采）
    线路输入 / 声卡：采集声卡输入（外置声卡、调音台输出）

· 设备
    切到某个音源类型时会自动重新扫描一次设备（刚插上的也能扫到）。
    软件会**按类型分别记住**你上次用的设备，切回该类型时自动选中。

· 采样率
    建议保持「自动（跟随系统）」。自动会跟随设备的原生采样率，
    避免系统重采样把鼓点的瞬态抹平 —— 能量判断会更准。
    只有在自动识别出问题时，才手动指定。

· 单声道分析
    一般开着。作用是在左右声道反相时避免低频被平均抵消 —— **不是为了省 CPU**（实测省得极少）。

· 增益
    采集信号太小时往上加。但如果已经能正常识别鼓点，就别动它。

· 当前采集设备 / 输入电平
    对话框里有实时电平表（总电平、低频、中频、高频），
    可以直观确认「软件到底听见没有、低频有没有进来」。

⚠ 现场如果软件像「听不见」，先看这里：切到系统声音，看电平表动不动。
⚠ 设备拔掉后下拉里会给出提示，重新选一个、点「应用」即可切换。


────────────────────────────────────────
四、素材库
────────────────────────────────────────
素材库有**两处**，是同一批素材：
  · 演出台上那份（和预览并排）——现场用，**拖进图层只能在这里拖**；
  · 第 2 个页签的全屏版——导入 / 筛选 / 打标签时用，看得清、好整理。
  两边的搜索框和筛选状态是**同步**的，切过去看到的就是同一个结果。
  不管在哪一份，双击缩略图都能立刻播放到当前图层。
  导入、扫描打标、改标签的按钮两处都有，做哪个都行。

【导入】
第一次导入会让你选导入方式，并可以勾「记住我的选择」：
  · 复制到素材库（原文件保留）：推荐。素材集中到一处，不怕原盘拔了
  · 移动到素材库：复制后删原文件，省空间
  · 仅引用：不复制，记原路径。移动 / 改名会失效
以后想改：素材库右键 →「导入素材设置…」。
导入是**后台进行**的：一次导入上千个 / 上百 GB 也不会卡住界面，
列表里会一批批冒出来，底部进度条显示进度，完成后提示「新增 N 个，跳过 M 个」。
（导入完记得点「扫描打标」，新素材才有标签可匹配。）

【扫描打标】
见上手流程第 3 步。可以重复点，只会补扫还没打过的。

【手动改标签】
右键素材 →「编辑标签…」，可以打勾 / 取消任意标签，也能输入自己的标签。
自动识别的标签是蓝底，你手动改过的以你为准，重扫不会覆盖。

【标签筛选】
素材库上方的「标签」下拉可以按标签筛素材；
点「筛选」能多选（素材含任一选中标签就显示）。

【排除素材】
logo、字幕这类固定素材，右键勾「排除自动打标 / 匹配」，
软件就不会把它当成随机切换的候选。

【清理】
右键 →「查看占用…」可以看缩略图缓存占了多少，并一键清理。


────────────────────────────────────────
五、图层
────────────────────────────────────────
一个图层 = 一路画面。多个图层会叠在一起显示（列表越靠上越在上面）。

【新建图层】
点图层区右上角的「+ 图层」，有三种类型：
  · 手动（自己拖素材）：你手动拖素材进去，软件只负责按节奏换
  · 自动（按曲风匹配画面）：软件识别到曲风后自动挑匹配的素材
  · Kv 主视觉图层：待机层，见第九节

【图层角色（仅自动图层）】
  · 背景：铺满全屏的环境画面（打底）
  · 前景：黑底 / 带透明通道的叠加元素（特效、光效）
  软件会按角色去挑不同类型的素材。点图层头上的「前景 / 背景」小按钮切换。

【图层头的颜色一眼区分】
  · 背景（自动）= 蓝色边框    · 前景（自动）= 橙色边框
  · Kv 主视觉 = 紫金边框

【图层头的小按钮】
  👁 显示 / 隐藏
  S  Solo（只显示本层）
  名字：单击选中，双击重命名
  滑条：不透明度
  α 保留素材自带透明通道（带 alpha 的 mov 才有区别）
  🔒 锁定画面（logo / 字幕用：不随音乐脉冲缩放）
  混合模式：常规 / 添加 / 屏幕 / 变亮……（前景叠加常用「添加」）

【右键菜单】
右键图层头或素材格子，可以重命名、固定播放、静音时暂停、
复制素材池到新图层、上移下移、重置本层设置、删除图层等。

【拖动】
素材可以在图层之间拖（拖到目标图层那一行）。
素材库的缩略图也能直接拖进图层；
另外**双击**缩略图 = 立即播放到当前图层（更快，演出中一只手就能用）。


────────────────────────────────────────
六、素材切换节奏（自动化核心）
────────────────────────────────────────
右侧「素材切换节奏」下拉，四种：

  · 自动（推荐）
      软件按音乐能量、曲风自动选节奏，现场基本用这个。

  · 常规切
      固定每 16 拍切一次素材（= 4 个 4/4 小节）。

  · 快切
      固定每 8 拍切一次素材（= 2 个 4/4 小节）。

  · 逐拍交替
      取一对素材 A、B，A↔B 快速交替（默认每 1 拍交替一次，
      也可设 1/4 拍、1/2 拍、2/4/8/16 拍）。
      选中它才会出现「逐拍交替参数」分区：
        素材选取：顺序 / 随机
        交替间隔：A↔B 多久交替一次
        每对小节数：多少小节换一对新素材
        末尾行为：播完循环 / 反向 / 停止

【什么时候会「立刻切」】
  · 能量跨档（安静段落突然炸开）：刻意设计，响应优先。
  · 曲风突然变化：会等下一个切换点再换（不打断画面）。

【其它】
  · 灵敏度：低 / 中 / 高。对能量波动更敏感（高 = 更容易切快）。
  · 过渡方式：跟随模式 / 淡入淡出 / 硬切 / 滑动 / 缩放 / 故障。
    跟随模式下：常规切 = 淡入淡出，逐拍交替 = 硬切。
  · 画面振幅强度：画面随音乐脉冲的程度。
  · BPM Sync 视频速度：素材播放速度跟着 BPM 走。
  · 渲染帧率：引擎每秒合成多少次画面。素材多为 25 到 30fps，选 60 时约有一半是把
    同一帧重复合成一遍 —— 机器吃紧（同时开 VDJ、直播、录制）就选 30，渲染占用约减半，
    画面仍跟得上素材；20 更省，但观感会明显变卡。
· GPU 解码：让显卡硬件解压 DXV 素材，降低解码 CPU 占用（仅对 DXV 编码的素材生效）。
默认关闭；显卡不支持或某个素材解不了会自动退回原来的方式，
    不会黑屏。**只影响普通图层，待机层（Kv）不受影响。**
    主工具条上「下一素材」右边也有一个同名开关，和这里联动，现场一键开关更方便。
    建议先在非演出时间试播一轮再上台；已经开着的素材要等下次切换才换方式。
    ✅ 早期版本切素材时偶发「无响应」并且一直卡死，原因是显卡驱动在**反复创建 / 销毁
      「显卡工作区」**时会挂住。现在整个程序**只创建一个工作区、运行期不再销毁**，这条
      路径已经彻底消除；万一显卡驱动仍然出问题，也只是那一个素材临时改走软件解码
      （画面继续播放），60 秒后自动尝试恢复，不会再把界面拖死。
      **可以放心长期开着这个开关。**
· 节拍网格（八拍乐句对齐）：认出曲库里的歌时，用离线算好的八拍网格驱动拍位，让素材切换踩在
  **八拍乐句头**（而不是随便一条 4 拍线）；音乐被调快调慢也能跟着对齐。关掉则完全回到原来的实时拍钟。
    · 只对「曲库里有网格、并且当场能被识别出来」的歌生效；没识别到就自动用原拍钟 ——
      和你现在看到的表现完全一样。
    · **开场约 20~40 秒在等识别稳定**，这段时间按原来的 4 拍对齐（**节奏是对的**，只是不带乐句层级）。
    · 少数「重复段落很多」的歌，可能短暂对到相邻的那条 4 拍线：**切点仍然踩在拍上**，不会错拍，
      通常 30~40 秒内自己纠正。
    · 电脑长时间卡顿时会自动静默退回原 4 拍对齐，不会卡死。
    · ⚠ 新版需要**先重新扫描一次曲库**（点「扫描分析」即可，只会补缺失的部分、不重跑指纹与联网）
      才会生成网格数据。
    · **现在每一首歌都能有网格**（早期版本只有被 VirtualDJ 分析过的歌才有，没装 VirtualDJ 就完全没有）。
      没有 VirtualDJ 数据的歌，会用**本地小节识别**离线补算一次：**每首约 2 秒**，一次性、算完入库，
      以后不再重算。所以**升级后第一次「扫描分析」会比平时慢一些**，之后就恢复正常速度。
    · 想确认本地小节识别准不准：看网格线的「●」小节头扫过时，音乐是不是正好换小节。
      万一某首歌整体错开（差 4 拍或差一拍），用下面那个「八拍相位翻转」，或按住听感手动判断。
    · 预览画面里、HUD 正下方会画一条**节拍网格线**（随音乐从左往右走）：
      「◆」= 八拍乐句头（**就是切换实际对齐的那条线**）、「●」= 小节头、「·」= 普通拍、最左白色游标 = 现在。
      想确认对齐对不对：看这条线扫到 ◆ 的时候，音乐是不是正好换句。锁定八拍后它会从 4 拍一组变成 8 拍一组
      （宽度变长就是这个意思）。
    · **如果某首歌听感上「差 4 拍」**（正好半个乐句 —— 离线是把"哪一个小节是乐句头"判反了），
      用「效果」面板里的 **「八拍相位翻转」**：只翻**当前正在放的这一首**、**点一下立刻生效**
      （不用重扫、不会打断已经对齐的拍位），并且会记进配置，下次放同一首仍然生效。再点一下翻回来。
      按下去之后，预览里那条网格线的 ◆ 会整条挪 4 拍 —— 对着音乐听一下就知道了。


────────────────────────────────────────
七、智能匹配（听歌识曲）
────────────────────────────────────────
【准备音乐曲库】
见上手流程第 5 步：第 3 个页签「🎵 曲库 · 曲风」→「🎵 音乐曲库…」
→「导入音乐文件夹」→「扫描分析」。
建议在演出前做完，扫一次以后不用再扫。

【曲库的排序 / 筛选】（这个页签左侧那一栏）
· **排序**：原顺序 / 曲名 / 艺人 / BPM 从低到高 / BPM 从高到低 /
  时长从短到长 / 时长从长到短。
· **BPM 区间**：全部 / 无节拍网格 / <100 / 100–128 / 128–150 / 150–180 / ≥180
· **时长**：全部 / 时长未知 / <3 分钟 / 3–5 分钟 / 5–7 分钟 / ≥7 分钟
· **只看文件缺失**：换盘、改名之后找不到文件的曲目，一份修复清单。
· 点「重置筛选」回到全部。

  ⚠ BPM 和时长来自**扫描建库时算的节拍网格**，不是随手抓的元数据。
  所以「无节拍网格」那一档 = 这些歌**用不了八拍乐句对齐**（切点对不到乐句头上），
  值得单独过一遍。新导入的歌要重新「扫描分析」才会补上网格。

【现场会发生什么】
  · 软件听到音乐，识别是哪首歌，知道曲风（比如 Techno）
  · 自动图层按曲风表映射成画面标签（科技 / 机械 / 未来 / 霓虹）
  · 从素材库里挑带这些标签的素材
  · 识别不到时，用本地 AI 实时判断曲风兜底

【曲风映射】
第 3 个页签「🎵 曲库 · 曲风」→「曲风映射…」里可以改「曲风 → 画面标签」的绑定关系：
· 左边**按大类**列出曲风（硬核系 / 浩室系 / Trance系 …），点大类展开，
  点一个曲风，右边勾它对应的画面标签。
· 每个大类末尾有「+ 新建曲风」：新建的曲风会记住所属大类，
  之后在「音乐曲库 → 纠正曲风」里也能选到它。
· 右边**顶部是「已选」**：当前曲风已勾的标签都列在上面，点一下即取消。
· 建议先按默认用，发现某类音乐配的画面不对再来调。


────────────────────────────────────────
八、能量与选材（不需要动，了解一下就行）
────────────────────────────────────────
软件实时算一个 0 到 1 的「能量」值，融合了响度、低频冲击、起伏量三路信号。

  能量很低或为 0：照常切换，只是节奏落到最慢档，并优先挑低动态素材
  低能量（低于 0.50）：切换变慢，偏中 / 低动态素材
  中能量（0.50 到 0.65）：正常切换
  高能量（0.65 以上）：切得更快，偏高动态 / 频闪素材

· 任何能量下素材都会一直切换（不会因为"没声音"就冻在同一个画面上）。

· 能量跨档（比如从安静段落进入 drop）会立刻重新挑素材池。
· 「能量校正」在实验性里，一般保持 1.0。
  只有现场系统开了很重的低频增强、导致能量虚高时才需要往右拉一点。


────────────────────────────────────────
九、Kv 主视觉图层（待机层）
────────────────────────────────────────
用途：没声音的时候把待机画面带进来，有声音的时候带出去。
      （比如换碟、说话、放广告时，屏幕上有一张品牌 / 氛围画面）

· 新建图层时选「Kv 主视觉图层」。
· 全局只能有一个；添加后自动置顶。
· 它完全独立：不受切换节奏、能量、曲风匹配、颜色渲染、后处理任何影响。
· 参数在右侧设置区最顶上（有 Kv 图层时才出现，删掉即收起）：
    静音判定阈值：-60 到 -20 dB，低于它算静音
    「自动检测底噪」：点一下监听环境 3 秒，自动设成比底噪高 3dB
    静音触发延迟：0 到 10 秒。声音消失后要静多久才切入
    声音恢复切出延迟：0.1 到 5 秒。有声音后要持续多久才切出
    切入方式 / 时长：淡入 / 硬切 / 故障，0.1 到 5 秒
    切出方式 / 时长：淡出 / 硬切 / 缩放，0.1 到 3 秒
    素材切换速度：0 到 60 秒。Kv 显示期间多久换一个素材，0 = 不换

现场建议：先点「自动检测底噪」，再按场地情况微调阈值。


────────────────────────────────────────
十、颜色渲染（一键调色）
────────────────────────────────────────
让同一批素材换个颜色就不一样，减少对素材数量的依赖。
位置：右侧「颜色渲染」（在「效果」和「后处理」之间）。

· 启用颜色渲染：总开关
· 自动模式：跟随音乐能量自动变色（默认开）
    能量低不染色 → 中段淡染 → 高潮浓染
    高能量下每隔一段时间平滑换一个颜色
· 色卡：点一下临时锁定一个颜色（10 秒后自动回到自动变色）
    原色 / 赛博紫 / 故障红 / 琥珀金 / 电光粉 / 深海蓝 / 霓虹青 / 霓虹绿
· Bypass：一键在原片和调色之间闪切（热键 C）
· 染色强度：整体浓淡，防止颜色过重盖住素材细节
· 高级设置：
    调色方式：LUT 调色（保留素材色彩）/ 双色调（最像换了个素材）
    色相轮换时间：1 到 60 秒
    能量突变强制刷新：能量突然跃升时立刻换一个高饱和颜色
    频闪素材：休眠 / 不休眠 / 随机（遇到频闪素材时怎么办）
    恢复自动变色：手动锁色后点它回到自动模式

注意：手动点色卡锁定的颜色**永远优先**，不受频闪设置影响。
      但 Kv 图层激活时一律不染色（铁的规矩）。


────────────────────────────────────────
十一、后处理（画面特效）
────────────────────────────────────────
右侧「后处理」。效果有：色差、辉光、故障位移、曝光脉冲、饱和度脉冲、
柔焦、拖影、颗粒、像素化、径向频谱、音频反应变形。
鼠标悬停在每一项上有说明。

两种模式：
· 自动：按曲风和能量自动挑 2 到 3 个合适的效果，强度跟着能量连续变化。
        公式是：强度 = 能量 × 全局强度的 60%
· 手动：你自己逐个开效果、调强度。手动模式**独立生效**，
        强度就是你设的值，不受全局强度影响。

自动模式什么时候换效果？
· 「效果保持」默认是「实时（跟随能量）」—— 效果跟着能量即时变。
  能量在门槛附近抖动时，效果会忽有忽无。
· 把它设成 8 / 16 / 32 / 64 拍，就会**选中一组效果先稳定保持那么多拍**，
  到点（或曲风变化）才重新挑下一组。想要变化有节奏感就用这个。
· **全局强度只决定效果「有多强」，不影响「多久换一次效果」。**

· 启用后处理：总开关（关着就什么特效都没有，先确认它是开的）
· 全局强度：只作用于自动模式，是自动效果的总闸门
· 自动联动：关掉后效果只跟能量走，不跟曲风 / 事件
· 齿轮按钮：**把「模式」切到「手动」**，每个效果右边就有齿轮按钮，
  可以设置触发方式（常驻 / 曲风 / 事件）、曲风绑定、衰减时长、音频驱动。
  （自动模式页没有效果列表，所以那里看不到齿轮。）

⚠ 如果发现「勾了效果但画面没变化」，先检查两个地方：
   ①「启用后处理」总开关是不是关的；②「全局强度」是不是被拉得很低。


────────────────────────────────────────
十二、输出
────────────────────────────────────────
点「显示输出窗口」→ 拖到第二块显示器 → 选「显示器 N 全屏」。

· 输出显示器：选「窗口模式（可拖动）」或某个显示器全屏
· 分辨率：1280x720 / 1920x1080 / 1080x1920(竖屏) / 1080x1080(方形)
            也可以直接输入，例如 1600 900
· 锁定 16:9：保持宽高比
· 无边框 / 窗口置顶
· 重置窗口大小：**严格按上面选的分辨率**重建输出窗口

说明：开始自动 VJ 时输出窗口会按你设的分辨率创建；
全屏时会**铺满整块屏幕**（720P 输出放到 1080P 屏上也会放大铺满），
宽高比不一致时画面居中、两边留黑边（不会缩在角落）。
上次关闭时记住的是**窗口位置**，不会改动你设的分辨率。

· Spout 输出：把画面实时共享给本机其它程序
                （OBS 装 Spout 插件后选这个 Sender）
                ⚠ Spout **只传画面，不含音频**；要声音请用 NDI 或虚拟声卡。
· NDI 输出：通过网络把画面发给其它电脑 / 软件。
                **运行时随软件一起提供，本机不需要安装任何东西**；
                只有**接收端**那台机器需要装 NDI Runtime。
· NDI 传输音频（48 kHz 立体声）：把采集到的声音随 NDI 一起发出去，**默认关闭**。
                ⚠ **此功能尚未完成，当前仅供测试**（界面上该项也标了「未完成」）。
                默认关是有意的：软件采集的是**系统回环**，接收端若本来就在
                监听同一路声音，再发一遍会变成双声 / 回声。只有接收端需要
                单独取声音时才勾选（要先勾上「NDI 输出」，这个开关才可点）。

⚠ 输出设置里的按钮要**点了「开始自动 VJ」之后**才可用，
   这是防止误触改错演出画面。

────────────────────────────────────────
十五、常见问题
────────────────────────────────────────
Q：软件像「听不见音乐」，画面不切？
A：① 检查「🎛 音源」里的输入电平表动不动；
   ② 系统声音模式下确认电脑确实在出声（有些声卡是独占模式）；
   ③ 看「当前能量」是不是一直接近 0。

Q：素材一直乱闪 / 切得太快？
A：① 看右侧是不是选了「快切」或「逐拍交替」；
   ② 能量反应太强时把「灵敏度」调到低；
   ③ 检查是不是有素材被误标成高动态 / 频闪，右键「编辑标签…」改掉。

Q：画面切来切去都是那几个素材？
A：① 给自动图层补更多素材；
   ② 确认做过「扫描打标」（没标签的素材很难被匹配到）；
   ③ 低能量段本来就只用低动态素材，可用范围会小一些。

Q：后处理勾了效果但画面没变化？
A：先看「启用后处理」总开关和「全局强度」；
   想改单个效果的细节，把「模式」切到「手动」，每个效果右边有齿轮按钮。

Q：想恢复出厂设置？
A：按 Ctrl+Shift+R（紧急恢复），或者删除数据文件夹（见下）。

Q：换电脑 / 重装后配置还在吗？
A：配置与缓存都在数据文件夹里，拷过去即可。

────────────────────────────────────────
