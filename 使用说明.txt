Easy Reality AutoVJ 1.1 使用说明
=============================

一、这是什么
------------
把音乐变成画面的实时 VJ 引擎。
它听正在放的歌，认出是哪一首，再按码表自动切换素材、跟拍、跟情绪。
DJ 只管放歌，画面这边它自己走；需要手动时随时能接手。


二、第一次启动
--------------
解压后双击 EasyRealityAutoVJ.exe 即可，不用安装。
配置、缩略图、指纹库、日志都在：
    %LOCALAPPDATA%\AutoVJ\
在「关于」里点「打开数据文件夹」也能直达。

第一次打开素材库和曲库都是空的，按下面四步走即可。


三、四步上手
------------
第 1 步 · 选音源
  点顶部「🎛 音源」，音源类型有五种：
    · 系统声音（WASAPI Loopback）—— 听本机正在放的音乐，最常用；
    · 麦克风 / 线路输入、声卡 —— 接外置声卡或 DJ 控制器；
    · ASIO（低延迟）—— 需要声卡自带 ASIO 驱动，只录声卡输入，
      抓不到别的程序播放的声音；
    · 局域网音频 —— 接收另一台电脑发来的声音。
  选好后看下方电平表有没有跳动；没有就换设备或点「重新扫描」。

第 2 步 · 扫描曲库（很重要，别跳过）
  打开「🎵 音乐曲库」，点「导入音乐文件」把歌加进来；
  如果手上已有曲库分析结果，也可以点「导入曲库分析…」。
  然后点「扫描分析」，它会给每首歌做三件事：
    · 建音频指纹 —— 现场靠它认出正在放的是哪首歌；
    · 算节拍网格 —— 八拍乐句对齐、码表卡点都靠它；
    · 分析能量段落 —— 进 drop 换素材池靠它。
  曲目多时在后台跑，可以同时去做第 3 步。
  列表里标「无节拍网格」的曲目要单独处理；没有指纹的歌现场认不出来，
  码表和能量段落都用不上。

第 3 步 · 导入素材、建图层
  · 导入：点素材库的「导入文件夹 / 导入文件」，或把文件夹直接拖进素材库。
    导入时会问一次方式：
      复制到素材库 / 移动到素材库 / 仅登记（不复制，保留原路径）。
    大素材包建议「仅登记」。
  · 打标：导入后点「扫描素材」。它先检测是否需要转码，再给视频打上
    动态（高/中/低）、频闪、铺满/局部和前景/背景角色。
    图片和 GIF 不参与扫描打标，只作为静态素材使用。
  · 图层：点图层区「+ 图层」。一般两张就够：
      背景 —— 铺满全屏的环境画面；
      前景 —— 黑底或带透明通道的叠加元素。
    把素材拖进图层，或双击缩略图 = 立刻播到当前图层。

第 4 步 · 开始
  点「▶ 开始」（Ctrl+Space）。画面开始跟着音乐自动切换。
  顶部随时可用：黑场、冻结、下一素材、暂停自动。
  要出画面：点「显示输出窗口」，或「多屏输出」把它放到第二块屏幕上。


四、四个页签
------------
🎬 演出台 —— 图层、预览、设置、输出，现场用这一页。
🗂 素材库 —— 导入、扫描、筛选、角色、预览，演出前的准备。
🎵 音乐曲库 —— 导入音乐、扫描分析、BPM 与能量段落。
🎞 码表 —— 导入 .ercue 码表包，绑到图层。


五、素材库
----------
· 筛选：全部 / 图片 / 视频 / 动态（高·中·低）/ 角色（前景·背景），
  右上角搜索框按文件名或标签搜。
· 右键素材：
    播放到图层、打开文件所在位置、重扫此素材、全量重扫、
    重建预览、角色（前景/背景）、排除自动匹配、从素材库移除。
  「排除自动匹配」给 logo、角标这类固定素材用：留在库里，但不会被自动挑中。
· 悬浮预览：鼠标停在视频上会弹出 10 帧胶片；缓存坏了就右键「重建预览」。
· 扫描素材做什么：
    1) 检测超宽（宽高比 ≥ 2.2）——不转码，只列出来提醒；
    2) 需要时转码：无 Alpha → DXV，带 Alpha → ProRes 4444；
    3) 打标：动态、频闪、铺满度、前景/背景。
  「全量重扫」会清掉旧标签重新算。
· GPU 解码：顶部「GPU 解码」开着时，DXV 素材走显卡解压，CPU 更低；
  显卡不支持会自动回退，不会黑屏。


六、图层与自动逻辑
------------------
· 图层越靠上显示越靠上；KV 主视觉图层永远置顶，不会被别的操作挤下去。
· KV（待机层）：没声音时把待机画面带进来，有声音时带出去。
  它完全独立，不参与自动切换，也不受其它设置影响。
· 自动怎么走：
    认歌（音频指纹）→ 读取这首歌的 BPM / 八拍网格 / 能量段落
    → 按能量和码表换素材池 → 素材按动态与角色自动挑选。
  没标能量段落的歌，按实测能量走。
· 手动：随时可以自己切素材、锁素材、暂停自动；松手再交回自动。
  全局强度只作用于自动模式，手动模式有自己独立的强度。
· 逐拍交替（设置区独立分区，默认关闭）：
  只作用于前景层、只在 drop 段触发；曲目没有能量段落表时不会触发。
  打开后一对素材 A↔B 默认每 1 拍交替，进入新段落才换下一对。
  快捷键 Ctrl+T 可以随时开关。


七、音乐曲库
------------
· 导入音乐：点「导入音乐文件」，或「导入曲库分析…」导入分析结果。
· 扫描分析：给曲目建指纹、节拍网格和能量段落。八拍乐句对齐要用节拍网格；
  没有网格的曲目会在列表里标出来。
· 右键曲目看详情：文件、歌名、艺人、曲风、时长、采样率、指纹 ID、
  波形与 BPM 分段。BPM 改完立即生效；多段 BPM 在波形上右键编辑。
· 能量段落：在波形上右键编辑「哪一段到哪一段、目标能量和档位」。
  演出时指纹一对齐就按这张表走，进 drop 直接换池。


八、码表
--------
码表 = 在 EasyRealityCue 里做好的成片，演出端只负责按拍播放。

1. 导入：第 4 个页签「导入码表包…」，选 .ercue（可多选）。
   导入时会把包里的指纹写进指纹库，之后才能自动认歌。
2. 绑图层：右键一行「绑到图层…」；或新建图层时类型选「码表图层」。
   绑好后图层头出现下拉：选表 = 换表，「（无码表）」= 卸下。
3. 播放：放歌即可。认到歌且这首歌有码表 ⇒ 自动接管；认不到 ⇒ 照常自动调度。
4. 临时停用：图层头下拉选「（无码表）」。
5. 「更多操作…」里还有：最近文件、手动绑歌、手动起拍、定位档位。
   认不到歌时可以手动绑曲 + 手动起拍照常播（起拍是估算，歌被拖动后要重新按）。


九、输出
--------
· 显示输出窗口：独立窗口，可拖到第二块屏，Ctrl+F 全屏。
· 多屏输出：一个界面里配多块屏——每块屏选对应显示器、模式、分辨率和裁切。
· NDI / Spout：画面作为「Easy Reality Output」源直出。
  本机走 TCP 回环，局域网走直连；OBS、Resolume 里直接选，不用采集卡。
  需要透明背景时勾「Spout/NDI 输出 Alpha」。
· 设置里的「屏幕设置 · 性能」可以调输出分辨率、渲染帧率、是否跟随素材帧率。


十、颜色与效果
--------------
· 颜色渲染：一键给整批素材换色，降低对素材数量的依赖。
  可选色卡、染色强度、色相轮换、能量映射；「自动联动」会随音乐触发。
  「Bypass」一键对比原色 / 调色，Ctrl+Shift+C。
· 后处理：辉光、颗粒、色差、故障位移、拖影、径向频谱、曝光脉冲等，
  按能量自动上效果，也可以关掉。
· KV 图层不受这些设置影响。


十一、快捷键
------------
顶部「⋯ 更多 → 快捷键」里可以查看、修改、启用/禁用，也能把「范围」设成全局。

  Ctrl+Space      开始 / 停止
  Ctrl+B          黑场
  Ctrl+Shift+F    冻结
  Ctrl+P          暂停自动
  Ctrl+Right      下一素材（默认全局：窗口没焦点也生效）
  Ctrl+Up / Down  自动强度 增 / 减
  Ctrl+Enter      手动切换
  Ctrl+L          锁定当前素材
  Ctrl+R          顺序 / 随机
  Ctrl+T          逐拍交替 开 / 关
  Ctrl+F          输出全屏
  Ctrl+H          显示 / 隐藏界面
  Ctrl+Shift+C    颜色 Bypass
  Ctrl+Shift+R    紧急恢复


十二、出问题看哪里
------------------
1. 日志目录（配置、缩略图、指纹库也在这里）：
       %LOCALAPPDATA%\AutoVJ\
   「关于 → 打开数据文件夹」可直接打开。
2. 反馈最快的方式：「⋯ 更多 → 导出全部日志…」，
   会把 *.log + config.json + 环境信息打成一个 zip，直接发作者。
3. 常见问题：
   · 画面不切 ⇒ 看「🎛 音源」电平表有没有动；没动就是没采到声音。
   · 素材挑不到 ⇒ 是否没「扫描素材」，或筛选/排除把素材挡掉了。
   · 黑屏 ⇒ 输出窗口是否开着、是否在第二块屏幕上。
   · 认不到歌 ⇒ 曲库有没有建指纹；码表包导入时指纹有没有入库。
   · 闪退 ⇒ 直接导出全部日志，连同崩溃时间一起发。
