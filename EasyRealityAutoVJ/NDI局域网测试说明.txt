NDI 局域网测试说明（Easy Reality AutoVJ）
================================================================

■ 这个工具是干什么的
用来确认「装了 AutoVJ 那台电脑」的画面，能不能通过局域网发到另一台电脑。
它自带 NDI 运行库，所以**接收端那台电脑什么都不用装**，双击就能用。
（不需要 NDI Tools，也不需要 OBS 插件。）

----------------------------------------------------------------
■ 一、接收端（另一台电脑）—— 就一步
----------------------------------------------------------------
把 NDI接收自检.exe 拷过去，双击运行。

它会自动：搜索局域网 → 连上 AutoVJ → 收 15 秒画面 → 打印结果。
结束时在同目录生成 ndi_received.bmp —— 双击打开，看到画面就是通了。

----------------------------------------------------------------
■ 二、发送端（装了 AutoVJ 那台）—— 三件事
----------------------------------------------------------------
1) 软件版本必须是 2026.09.25.02 或更新。
   【重要】更早的版本 NDI 输出是坏的：开关能打开、接收端也能搜到源，
   但一帧画面都发不出去（黑屏）。这个 bug 在 092502 修好了。

2) 打开软件 →「输出」面板 → 勾上「NDI 输出（音画同步）」。
   右边的「NDI 源名称」可以用默认值，接收端看到的就是
   「电脑名 (EasyRealityAutoVJ)」。

3) 防火墙放行 + 网络类型设为「专用网络」。
   以【管理员身份】运行一次「命令提示符」，把下面三条粘贴执行：
     netsh advfirewall firewall add rule name="NDI" dir=in action=allow protocol=UDP localport=5353
     netsh advfirewall firewall add rule name="NDI TCP" dir=in action=allow protocol=TCP localport=5960-5990
     netsh advfirewall firewall add rule name="NDI UDP" dir=in action=allow protocol=UDP localport=5960-5990
   再把网络类型改掉（「公用网络」会挡掉 NDI 的发现广播）：
     设置 → 网络和 Internet → 以太网 / WLAN → 网络配置文件类型 → 选「专用网络」

----------------------------------------------------------------
■ 重要：NDI 源只在「软件真的在输出画面」时才存在
----------------------------------------------------------------
软件**开着但没开始播放**（没点「开始自动 VJ」/ 没有画面在合成）时，**是不发 NDI 的**。

原因：发送端是在**第一帧画面到来时**才按实际输出分辨率建立的。
没有帧 → 没有发送端 → 另一台电脑自然一个源都搜不到。

所以「另一台扫不到源」时，第一条要确认的就是：**这台正在输出画面吗**（预览窗口有内容）。
停止运行（不再合成画面）后源也会消失。

这条最容易被误判成"网络问题"，白白折腾防火墙和网线。

----------------------------------------------------------------
■ 三、结果怎么读（自检工具会直接告诉你）
----------------------------------------------------------------
· 发现 0 个源            → 发送端那三件事没做全（多半是 NDI 开关没开，或防火墙）
· 发现了源、但没有 AutoVJ → 发送端软件的「NDI 输出」没打开
· 连不上（connected=False）→ 发送端防火墙没放行
· 连上了但 0 帧          → 发送端软件没在播放（没有画面可发），或版本太旧
· 收到 N 帧 + 生成截图    → 通了

----------------------------------------------------------------
■ 四、都做了还是搜不到
----------------------------------------------------------------
· 两台电脑必须在同一局域网、同一网段（IP 前三段相同）。
· 路由器若开了「AP 隔离 / 客户端隔离」，设备之间互相看不见 → 关掉它。
· 有些无线中继 / 交换机不吃 mDNS 多播 → 换有线再试一次。
· 局域网里有同名的 NDI 源时会冲突 → 在软件里换一个「NDI 源名称」。

----------------------------------------------------------------
■ 五、确认能收之后
----------------------------------------------------------------
接收端要长期看画面，可以装官方的「NDI Studio Monitor」（免费），
或在 OBS 里装 NDI 插件后添加「NDI Source」源。

成本提示：NDI 发送端实测约占 0.3 个 CPU 核（1080p 60fps），
渲染帧率从 60 降到 30 时这个开销也减半。
