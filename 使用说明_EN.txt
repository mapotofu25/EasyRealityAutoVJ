Easy Reality AutoVJ 1.0 — User Guide
====================================

1. What this is
---------------
A real-time VJ engine that turns music into visuals.
It listens to the track that is playing, recognizes it, and follows a cue sheet
you prepared earlier to decide what should be on screen. Clip changes, beat sync
and mood are handled for you — the DJ just plays, and you are not glued to the
laptop cueing the next clip. Step in manually whenever you want.


2. First launch
---------------
Unzip and run EasyRealityAutoVJ.exe. No installation required.
Configuration, thumbnails, the fingerprint database and logs live in:
    %LOCALAPPDATA%\AutoVJ\
You can also open that folder from "About -> Open data folder".

The library and music library start empty. Follow the four steps below.


3. Four steps to get going
--------------------------
Step 1 - Choose an audio source
  Click "Audio source" in the top bar. There are five types:
    - System sound (WASAPI Loopback) — hears what this PC is playing; most common.
    - Microphone / Line input, sound card — for an external interface or DJ controller.
    - ASIO (low latency) — requires the card's own ASIO driver; captures the card's
      inputs only, not other applications' playback.
    - LAN audio — receives sound sent from another computer.
  Watch the level meters below; if nothing moves, pick another device or click
  "Rescan".

Step 2 - Scan the music library (important, do not skip)
  Open "Music Library", click "Import music files" (or "Import library analysis..."
  if you already have an analysis package).
  Then click "Scan / analyze". For every track it builds:
    - an audio fingerprint — used to recognize the track live;
    - a beat grid — used for 8-beat phrase alignment and cue-sheet timing;
    - energy sections — used to switch clip pools on drops.
  Large libraries run in the background; you can start step 3 meanwhile.
  Tracks marked "no beat grid" need attention. Tracks without a fingerprint
  cannot be recognized live, and cue sheets / energy sections will not apply.

Step 3 - Import clips and build layers
  - Import: click "Import folder" / "Import files" in the Library, or drag a folder
    into the grid. You will be asked once how to import:
      Copy into library / Move into library / Link only (keep original path).
    For large packs, "Link only" is recommended.
  - Tagging: click "Scan clips". It first checks whether transcoding is needed,
    then tags each video with motion (high/mid/low), flicker, coverage
    (full/partial) and role (foreground/background).
    Images and GIFs are not scanned or tagged; they are used as static clips.
  - Layers: click "+ Layer". Two layers are usually enough:
      Background — full-frame environment visuals;
      Foreground — black-based or alpha overlays (light effects, elements).
    Drag clips into a layer, or double-click a thumbnail to play it on the
    current layer.

Step 4 - Start
  Click "Start" (Ctrl+Space). Visuals begin following the music automatically.
  Always available in the top bar: Blackout, Freeze, Next clip, Pause auto.
  For output: click "Show output window", or "Multi-screen output" to place it on
  a second display.


4. The four tabs
----------------
Live — layers, preview, settings and output; the page you use during a show.
Library — import, scan, filter, roles and previews; preparation before a show.
Music Library — import tracks, scan/analyze, BPM and energy sections.
Cue Sheets — import .ercue cue-sheet packages and bind them to layers.


5. Library
----------
- Filters: All / Images / Videos / Motion (high, mid, low) / Role (foreground,
  background). The search box matches file names or tags.
- Right-click a clip:
    Play on layer, Open file location, Rescan this clip, Rescan all,
    Rebuild preview, Role (foreground/background), Exclude from auto matching,
    Remove from library.
  "Exclude from auto matching" is for logos and bugs: they stay in the library
  but are never picked automatically.
- Hover preview: rest the mouse on a video to see a 10-frame filmstrip. If the
  cache is broken, right-click "Rebuild preview".
- What "Scan clips" does:
    1) Detects ultra-wide clips (aspect ratio >= 2.2) — not transcoded, only listed;
    2) Transcodes when needed: no alpha -> DXV, alpha -> ProRes 4444;
    3) Tags motion, flicker, coverage and role.
  "Rescan all" clears old tags and recomputes everything.
- GPU decode: with "GPU decode" enabled, DXV clips are decompressed on the GPU,
  using much less CPU. Unsupported cards/clips fall back automatically — never
  a black screen.


6. Layers and automatic behavior
--------------------------------
- Layers higher in the stack draw on top. The KV main-visual layer is always kept
  on top and cannot be pushed down by other operations.
- KV (idle layer): brings the idle visual in when there is no sound and out when
  audio returns. It is fully independent of automatic switching and every other
  setting.
- How automation works:
    recognize the track (audio fingerprint) -> read its BPM / 8-beat grid /
    energy sections -> switch clip pools on section boundaries -> pick clips by
    motion level and role.
  Tracks without energy sections fall back to measured energy.
- Manual: you can switch clips, lock a clip or pause automation at any time.
  Release it and automation takes over again. Global intensity affects automatic
  mode only; manual mode has its own intensity.
- Beat alternation (separate settings section, off by default):
  foreground layers only, and only inside drop sections. Tracks without an
  energy-section table will not trigger it. When enabled, a pair of clips
  alternates A<->B once per beat by default; a new pair is chosen only when a new
  section starts. Ctrl+T toggles it at any time.


7. Music Library
----------------
- Import tracks: "Import music files", or "Import library analysis..." to load an
  analysis package.
- Scan / analyze: builds fingerprints, beat grids and energy sections. 8-beat
  phrase alignment needs the beat grid; tracks without one are marked in the list.
- Right-click a track for details: file, title, artist, genre, duration, sample
  rate, fingerprint ID, waveform and BPM segments. BPM edits apply immediately;
  multi-tempo tracks are edited by right-clicking the waveform.
- Energy sections: right-click the waveform to edit "which range, target energy
  and tier". During a show, once the fingerprint locks, playback follows that
  table and switches pools right on the drop.


8. Cue Sheets
-------------
A cue sheet is a finished arrangement made in EasyRealityCue; the live app only
plays it on the beat.

1. Import: the 4th tab -> "Import cue sheet package", select .ercue files
   (multiple selection supported). Their fingerprints are written into the local
   fingerprint database during import, which is required for live recognition.
2. Bind: right-click a row -> "Bind to layer..."; or create a layer of type
   "Cue-sheet layer". Once bound, the layer header shows a drop-down:
   select a sheet to switch, or "(no cue sheet)" to unload.
3. Play: just play music. If the track is recognized and has a cue sheet, the
   sheet takes over; otherwise normal automation continues.
4. Temporarily disable: choose "(no cue sheet)" in the layer header.
5. "More actions..." also contains: recent files, manual track binding, manual
   downbeat and seek quality. If recognition fails, bind the track and tap the
   first beat manually (the downbeat is estimated; re-tap after seeking).


9. Output
---------
- Show output window: a separate window you can move to a second display;
  Ctrl+F goes fullscreen.
- Multi-screen output: configure several screens in one place — display, mode,
  resolution and crop per screen.
- NDI / Spout: the picture is published as "Easy Reality Output".
  Same machine uses a TCP loopback; LAN uses a direct connection. Pick it
  directly in OBS or Resolume, no capture card required.
  Enable "Spout/NDI output alpha" when you need transparency.
- "Screen settings - Performance" controls output resolution, render frame rate
  and whether to follow the source frame rate.


10. Color and effects
---------------------
- Color rendering: recolor a whole batch of clips, reducing reliance on clip
  quantity. Palette, strength, hue rotation and energy mapping are available;
  "Auto link" follows the music. "Bypass" compares original vs graded with one
  click (Ctrl+Shift+C).
- Post effects: glow, grain, chromatic aberration, glitch displacement, trails,
  radial spectrum, exposure pulse and more. They can follow energy automatically
  or be turned off.
- The KV layer is not affected by these settings.


11. Hotkeys
-----------
Open "More -> Hotkeys" to view, edit, enable/disable them, and set the scope to
global.

  Ctrl+Space      Start / Stop
  Ctrl+B          Blackout
  Ctrl+Shift+F    Freeze
  Ctrl+P          Pause automation
  Ctrl+Right      Next clip (global by default: works when the window is unfocused)
  Ctrl+Up / Down  Automation intensity up / down
  Ctrl+Enter      Manual transition
  Ctrl+L          Lock current clip
  Ctrl+R          Sequential / random
  Ctrl+T          Beat alternation on / off
  Ctrl+F          Output fullscreen
  Ctrl+H          Show / hide interface
  Ctrl+Shift+C    Color bypass
  Ctrl+Shift+R    Emergency reset


12. Troubleshooting
-------------------
1. Logs (configuration, thumbnails and fingerprint DB live here too):
       %LOCALAPPDATA%\AutoVJ\
   Open it from "About -> Open data folder".
2. Fastest way to report a problem: "More -> Export all logs...". It bundles
   *.log + config.json + environment info into one zip — send that to the author.
3. Common issues:
   - Visuals do not switch: check the "Audio source" level meters. If nothing
     moves, no audio is being captured.
   - Clips are never picked: run "Scan clips", or check whether filters /
     exclusions are hiding them.
   - Black screen: is the output window open, and on the second display?
   - Track not recognized: does the music library have a fingerprint? Did the
     cue-sheet package import its fingerprints?
   - Crash: export all logs and include the time of the crash.
